## 第 1 章 为什么要学位运算

位运算（bitwise operation）直接操作整数的二进制位，是 C++ 中最贴近硬件的一层抽象。它值得学，原因有四个：

| 价值 | 说明 |
| --- | --- |
| **极致的效率** | 一次 CPU 指令完成，无分支、无函数调用，比算术运算快一个量级 |
| **极致的压缩** | 用一个 `uint64_t` 表示 64 个布尔状态，内存占用降为 `bool[64]` 的 1/64 |
| **表达能力** | 权限系统、状态压缩 DP、位图索引、哈希、编解码都靠它 |
| **面试与算法** | 位运算题出现频率极高，且往往是唯一的最优解法 |

典型落地场景：

- **权限/开关系统**：Linux 文件权限 `chmod 755`、epoll 事件标志、OpenGL 状态位
- **海量数据去重**：40 亿个不重复整数用 512 MB 位图即可判重（经典面试题）
- **状态压缩 DP**：旅行商问题（TSP）把"已访问城市集合"压成一个整数
- **高性能计算**：快速幂、快速乘、SIMD 前的位级优化
- **协议与编解码**：IP 子网掩码、图像位深打包、格雷码编码器
- **哈希与概率结构**：布隆过滤器、HyperLogLog 的分桶

> **为什么位运算是面试高频考点？** 位运算题测试的是你对数据在硬件层面如何存储和操作的理解。Google、Microsoft 等公司经常出这类题，因为它能区分出真正理解计算机工作原理的候选人和只背算法的候选人。很多看起来需要复杂数据结构的问题，用位运算可以用 O(1) 空间和极快的速度优雅解决。


## 第 2 章 二进制与补码：位运算的地基

### 2.1 现代计算机统一用「补码」表示有符号整数

这是理解位运算的第一道门槛： **`-x` 在机器里不是“符号位 + 绝对值”，而是“取反加一”** 。

定义（w 位）：

```
[x]补 = 2^w - x    (当 x < 0)
[x]补 = x          (当 x >= 0)
```

一个更实用的等价说法： **`~x + 1 == -x`** ，反过来 **`~x == -x - 1`** 。

**验证代码：**

```cpp
#include <cstdint>
#include <cstdio>

void bin32(uint32_t x) {                 // 打印 32 位二进制
    for (int i = 31; i >= 0; --i) putchar((x >> i) & 1u ? '1' : '0');
}

int main() {
    for (int v : {5, -5}) {
        uint32_t u = static_cast<uint32_t>(v);
        printf("%3d -> ", v); bin32(u); printf("  (0x%08X)\n", u);
    }
    printf("~5 = %d, ~5u = %u\n", ~5, ~5u);
    printf("-1 == ~0 : %d\n", -1 == ~0);
}
```

**真实输出：**

```
  5 -> 00000000000000000000000000000101  (0x00000005)
 -5 -> 11111111111111111111111111111011  (0xFFFFFFFB)
~5 = -6, ~5u = 4294967290
-1 == ~0 : 1
```

注意三个关键点：

1. `-5` 的十六进制是 `0xFFFFFFFB`，高位全是 1——**负数右移时补 1 就是这个原因**。
2. `~5` 是 `-6`，不是 6。因为 `~5 = -5 - 1`。
3. `~0 == -1`，所以 **`~0` 常被用作“全 1 掩码”** 。

### 2.2 为什么用补码

因为补码让**加减法统一**：`5 + (-5)` 直接按无符号规则相加就得到 0，CPU 不需要为减法单独设计电路。

```
  00000000000000000000000000000101   (5)
+ 11111111111111111111111111111011   (-5)
= 100000000000000000000000000000000  (溢出位丢弃)
  00000000000000000000000000000000   (0)  ✅
```

### 2.3 位宽与类型选择

**永远不要用 `int` / `long` 做位运算，用固定宽度类型：**

```cpp
#include <cstdint>
using u8  = std::uint8_t;
using u32 = std::uint32_t;
using u64 = std::uint64_t;
```

| 类型 | 位宽 | 无符号范围 | 常用场景 |
| --- | --- | --- | --- |
| `uint8_t` | 8 | 0 ~ 255 | 单个字节、颜色通道 |
| `uint16_t` | 16 | 0 ~ 65535 | 协议字段 |
| `uint32_t` | 32 | 0 ~ 42.9 亿 | 通用位运算、哈希 |
| `uint64_t` | 64 | 0 ~ 1.8e19 | 位图、状态压缩、大集合 |

原因：`long` 在 Linux 是 64 位、在 Windows 是 32 位，跨平台会出诡异 bug。

### 2.4 二进制字面量

```cpp
auto a = 0b1010'1010u;   // C++14 起支持，' 是分隔符，可读性好
auto b = 0xFFu;          // 十六进制，每 4 位一组，最常用
auto c = 0377u;          // 八进制（少用，容易看错）
std::bitset<8> bs(0b10101010u);
std::cout << bs << "\n"; // 输出 10101010
```


## 第 3 章 六大运算符全解

C++ 提供 6 个位运算符：

| 运算符 | 名称 | 规则 | 优先级 |
| --- | --- | --- | --- |
| `~` | 按位取反（NOT） | 0→1，1→0 | 高（单目） |
| `&` | 按位与（AND） | 全 1 才 1 | 中 |
| `^` | 按位异或（XOR） | 不同才 1 | 低 |
| `\|` | 按位或（OR） | 有 1 就 1 | 最低 |
| `<<` | 左移 | 低位补 0 | 中 |
| `>>` | 右移 | 高位补 0 或符号位 | 中 |

### 3.1 `&` 按位与 —— 提取与屏蔽

```
  1101 1010   (0xDA)
& 0000 1111   (0x0F，掩码)
= 0000 1010   (0x0A)  ← 只保留低 4 位
```

**三大用途：**

```cpp
x & 1            // 判断奇偶：结果为 1 则是奇数
x & (x - 1)      // 清除最低位的 1
x & (-x)         // 取出最低位的 1（lowbit）
x & mask         // 提取指定字段
(x & (n - 1))    // 当 n 是 2 的幂时，等价于 x % n（比取模快）
```

### 3.2 `|` 按位或 —— 合并与置位

```
  1101 0000
| 0000 1011
= 1101 1011
```

**用途：** 组合标志位。`OPEN_READ | OPEN_WRITE | O_CREAT` 就是典型写法。

### 3.3 `^` 按位异或 —— 最“聪明”的运算符

异或的 6 条性质，全部能通向算法题：

```
a ^ a = 0          // 自反：任何数与自己异或清零
a ^ 0 = a          // 与 0 异或不变
a ^ b = b ^ a      // 交换律
(a ^ b) ^ c = a ^ (b ^ c)  // 结合律
a ^ b ^ b = a      // 由此推出：偶数次的数会被自动消掉
a ^ b = c  ⟺  a ^ c = b  ⟺  b ^ c = a   // 可逆性
```

**用途：** 找唯一数、不用临时变量交换、加密算法、格雷码、奇偶校验。

### 3.4 `~` 按位取反 —— 构造反掩码

```cpp
x & ~(1u << k)    // 清除第 k 位（~ 造出“只有第 k 位是 0”的掩码）
~0u               // 全 1 掩码（32 位）
~0ULL             // 全 1 掩码（64 位）
```

⚠️ **`~` 会作用于所有位**，包括你不想动的高位，所以必须配合 `&` 使用。

### 3.5 `<<` 左移 —— 乘以 2^n

```cpp
1u << k           // 构造“只有第 k 位是 1”的掩码
x << 1            // x * 2
x << 3            // x * 8
```

⚠️ **两个致命陷阱：**

```cpp
1 << 40           // ❌ 未定义行为！1 是 int，只有 32 位
1ULL << 40        // ✅ 正确
1 << 32           // ❌ 未定义行为！移位数 >= 位宽
```

### 3.6 `>>` 右移 —— 除以 2^n

```cpp
x >> 1            // x / 2（向下取整）
x >> 3            // x / 8
```

⚠️ **有符号数右移是「算术右移」（补符号位），无符号数右移是「逻辑右移」（补 0）：**

```cpp
int8_t  a = -8;      // 1111 1000
a >> 1;              // 1111 1100 = -4  （补 1，仍是负数）
uint8_t b = 248;     // 1111 1000
b >> 1;              // 0111 1100 = 124 （补 0）
```

同一串比特，结果天差地别。**做位运算请一律用无符号类型。**


## 第 4 章 位操作技巧速查手册

以下均假设 `x` 为无符号整数，位编号从 **0（最低位）** 开始。

### 4.1 单比特操作

| 目标 | 写法 | 说明 |
| --- | --- | --- |
| 读第 k 位 | `(x >> k) & 1u` | 得到 0 或 1 |
| 置第 k 位为 1 | `x \|= (1u << k)` | 幂等，重复执行结果不变 |
| 置第 k 位为 0 | `x &= ~(1u << k)` | |
| 翻转第 k 位 | `x ^= (1u << k)` | 开关切换 |
| 置第 k 位为 v | `x = (x & ~(1u<<k)) \| (v << k)` | v 为 0 或 1 |

### 4.2 多比特字段操作

把 bit[4..7] 当作一个 4 位字段：

```cpp
// 提取 bit[lo..hi]（含两端）
uint32_t get_field(uint32_t x, int lo, int hi) {
    return (x >> lo) & ((1u << (hi - lo + 1)) - 1);
}

// 写入 bit[lo..hi] = val
uint32_t set_field(uint32_t x, int lo, int hi, uint32_t val) {
    uint32_t mask = ((1u << (hi - lo + 1)) - 1) << lo;
    return (x & ~mask) | ((val << lo) & mask);
}
```

### 4.3 掩码构造

| 目标 | 写法 |
| --- | --- |
| 低 n 位全 1 | `(1u << n) - 1` |
| 第 k 位起共 n 位为 1 | `((1u << n) - 1) << k` |
| 全 1 | `~0u` / `~0ULL` |
| 清除最低位的 1 | `x & (x - 1)` |
| 保留最低位的 1 | `x & (-x)` 或 `x & (~x + 1)` |
| 最低位 1 及其后全变 1 | `x \| (x - 1)` |
| 最低位 0 及其后全变 1 | `x \| (x + 1)` |

### 4.4 经典判断与计算

| 目标 | 写法 | 原理 |
| --- | --- | --- |
| 判断奇偶 | `(x & 1) != 0` | 最低位决定奇偶 |
| 判断是否为 2 的幂 | `x != 0 && (x & (x-1)) == 0` | 2 的幂只有 1 个 1 |
| 统计 1 的个数 | Brian Kernighan 循环（见案例 3） | 每次清掉一个 1 |
| 求以 2 为底的对数 | `31 - __builtin_clz(x)` 或 C++20 `bit_width(x)-1` | 最高位 1 的位置 |
| 向上取整到 2 的幂 | C++20 `std::bit_ceil(x)` | |
| 交换两数 | `a^=b; b^=a; a^=b;` | 异或可逆 |
| 取绝对值 | `int m = n>>31; return (n^m)-m;` | 负数时 m=-1（全1） |
| 取 min / max | `min = y ^ ((x^y) & -(x<y))` | 无分支 |
| 大小写互转 | `c ^ ' '`（即 `c ^ 0x20`） | 大小写 ASCII 差 32 |
| 字符转数字 | `c & 0x0F` | 仅对 '0'~'9' 有效 |
| 取模（n 为 2 的幂） | `x & (n - 1)` | 比 `%` 快很多 |
| 判断两数同号 | `(a ^ b) >= 0` | 符号位异或为 0 |

### 4.5 无分支写法示例（消除分支预测失败）

```cpp
// 分支版：CPU 可能预测失败，流水线清空
int max_branch(int a, int b) { return a > b ? a : b; }

// 无分支版
int max_bit(int a, int b) {
    int mask = -(a > b);        // a>b 时 mask = 0xFFFFFFFF
    return a ^ ((a ^ b) & mask);
}
```

> 现代编译器对简单三目运算通常会自动生成 `cmov` 指令，手写无分支不一定更快，但在 GPU、SIMD、常数时间密码学场景下必须用。


## 第 5 章 实战案例（可运行）

> 以下每个案例都给出完整代码 + **真实运行输出**。

### 案例 1：寄存器风格的位操作（置位 / 清位 / 翻转 / 读位）

```cpp
#include <cstdint>
#include <cstdio>
using u32 = std::uint32_t;

void bin32(u32 x) { for (int i = 31; i >= 0; --i) putchar((x >> i) & 1u ? '1' : '0'); }

int main() {
    u32 reg = 0x0Fu;                   // 0000 1111
    printf("orig      : "); bin32(reg); putchar('\n');

    reg |= (1u << 5);                  // 置位 bit5
    printf("set bit5  : "); bin32(reg); putchar('\n');

    reg &= ~(1u << 2);                 // 清位 bit2
    printf("clr bit2  : "); bin32(reg); putchar('\n');

    reg ^= (1u << 0);                  // 翻转 bit0
    printf("tgl bit0  : "); bin32(reg); putchar('\n');

    printf("read bit5 : %u\n", (reg >> 5) & 1u);

    // 连续字段：把 bit4~bit7 整体写成 0xA
    reg = (reg & ~(0xFu << 4)) | (0xAu << 4);
    printf("field 4..7 = 0xA : 0x%02X\n", (reg >> 4) & 0xFu);
}
```

**输出：**

```
orig      : 00000000000000000000000000001111
set bit5  : 00000000000000000000000000101111
clr bit2  : 00000000000000000000000000101011
tgl bit0  : 00000000000000000000000000101010
read bit5 : 1
field 4..7 = 0xA : 0x0A
```

### 案例 2：权限位系统（生产环境最常用）

一个 `uint32_t` 存 32 种权限，数据库只存一个整数，判权限一次 `&` 搞定。

```cpp
#include <cstdint>
#include <cstdio>
using u32 = std::uint32_t;

enum Perm : u32 {
    NONE  = 0,
    READ  = 1u << 0,   // 1
    WRITE = 1u << 1,   // 2
    EXEC  = 1u << 2,   // 4
    ADMIN = 1u << 3    // 8
};

bool has(u32 p, Perm bit)     { return (p & bit) != 0; }
bool has_all(u32 p, u32 bits) { return (p & bits) == bits; }

int main() {
    u32 alice = READ | WRITE;          // 3
    u32 bob   = READ | EXEC | ADMIN;   // 13
    printf("alice=%u bob=%u\n", alice, bob);

    printf("alice 可读? %d\n",  has(alice, READ));
    printf("alice 可执行? %d\n", has(alice, EXEC));
    printf("alice 有读写全部? %d\n", has_all(alice, READ | WRITE));

    alice |= EXEC;    printf("授权 EXEC 后 alice=%u\n", alice);    // 7
    alice &= ~WRITE;  printf("回收 WRITE 后 alice=%u\n", alice);   // 5
    alice ^= READ;    printf("翻转 READ 后 alice=%u\n", alice);    // 4

    printf("交集(共同权限)=%u, 并集=%u\n", alice & bob, alice | bob);
}
```

**输出：**

```
alice=3 bob=13
alice 可读? 1
alice 可执行? 0
alice 有读写全部? 1
授权 EXEC 后 alice=7
回收 WRITE 后 alice=5
翻转 READ 后 alice=4
交集(共同权限)=4, 并集=13
```

**工程提示：** 权限位要持久化时，用 `uint64_t` 字段存 DB；接口返回时再展开成 `["READ","EXEC"]`。注意 64 位权限上限——超过 64 个权限需改用 `std::bitset<N>` 或 `vector<uint64_t>` 位图。

### 案例 3：lowbit、统计 1 的个数、判断 2 的幂

```cpp
#include <bit>
#include <cstdint>
#include <cstdio>
using u32 = std::uint32_t;

int popcount_bk(u32 x) {            // Brian Kernighan 算法
    int c = 0;
    while (x) { x &= x - 1; ++c; }  // 每轮清掉最低位的 1
    return c;
}

bool is_power2(u32 x) { return x != 0 && (x & (x - 1)) == 0; }

int main() {
    for (u32 x : {12u, 16u, 40u}) {
        printf("x=%2u lowbit=%2u  %s\n", x, x & (~x + 1u),
               is_power2(x) ? "是2的幂" : "不是2的幂");
    }
    printf("popcount(0b1011000) = %d\n", (int)std::popcount(0b1011000u));

    u32 x = 0b10110100u;
    printf("Kernighan popcount(%u) = %d\n", x, popcount_bk(x));
}
```

**输出：**

```
x=12 lowbit= 4  不是2的幂
x=16 lowbit=16  是2的幂
x=40 lowbit= 8  不是2的幂
popcount(0b1011000) = 3
Kernighan popcount(180) = 4
```

**复杂度：** Kernighan 算法是 O(k)，k 为 1 的个数，比逐位检查的 O(w) 快。工业界首选 `std::popcount`（编译为单条 `popcnt` 指令）。

**lowbit 的重要应用 —— 树状数组（Fenwick Tree）：**

```cpp
int lowbit(int x) { return x & -x; }
void add(int idx, int delta) { for (; idx <= n; idx += lowbit(idx)) tree[idx] += delta; }
int  sum(int idx)            { int s = 0; for (; idx > 0; idx -= lowbit(idx)) s += tree[idx]; return s; }
```

### 案例 4：只出现一次的数字（异或消元）

```cpp
#include <cstdio>
int main() {
    int a[] = {4, 1, 2, 1, 2, 7, 4};
    int ans = 0;
    for (int v : a) ans ^= v;    // 出现两次的数自相抵消
    printf("数组: "); for (int v : a) printf("%d ", v);
    printf("-> 唯一数 = %d\n", ans);
}
```

**输出：**

```
数组: 4 1 2 1 2 7 4 -> 唯一数 = 7
```

**原理：** `a^a=0`，`a^0=a`，且异或满足交换律结合律，所以 `(4^4)^(1^1)^(2^2)^7 = 7`。

**进阶（出现三次的变种）** ：用两个变量分别记录“出现 1 次的位”和“出现 2 次的位”：

```cpp
int singleNumberIII(vector<int>& nums) {
    int one = 0, two = 0;
    for (int x : nums) {
        one = (one ^ x) & ~two;
        two = (two ^ x) & ~one;
    }
    return one;
}
```

### 案例 5：不用 `+` 实现加法（以及减法）

```cpp
#include <cstdio>

int add(int a, int b) {                 // 异或=无进位和，与+左移=进位
    while (b) {
        unsigned carry = (unsigned)(a & b) << 1;
        a ^= b;
        b = (int)carry;
    }
    return a;
}
int neg(int n) { return add(~n, 1); }   // 取负：取反加一
int sub(int a, int b) { return add(a, neg(b)); }

int main() {
    printf("add(17, 25) = %d\n", add(17, 25));
    printf("add(-13, 8) = %d\n", add(-13, 8));
    printf("sub(30, 12) = %d\n", sub(30, 12));
}
```

**输出：**

```
add(17, 25) = 42
add(-13, 8) = -5
sub(30, 12) = 18
```

**原理：**
- `a ^ b` = 不考虑进位时的和
- `(a & b) << 1` = 进位
- 反复迭代直到进位为 0

⚠️ 注意 `carry` 用 `unsigned` 左移，避免有符号数左移溢出导致的未定义行为。

### 案例 6：快速幂（二进制幂）

```cpp
#include <cstdint>
#include <cstdio>
using u64 = std::uint64_t;

u64 qpow(u64 a, u64 n, u64 mod) {
    u64 r = 1 % mod;
    a %= mod;
    while (n) {
        if (n & 1) r = r * a % mod;   // 指数的当前位为 1，累乘
        a = a * a % mod;              // 底数平方
        n >>= 1;                      // 指数右移一位
    }
    return r;
}

int main() {
    printf("3^13 = %llu\n", (unsigned long long)qpow(3, 13, 1000000007ULL));
    printf("2^100 mod 1e9+7 = %llu\n", (unsigned long long)qpow(2, 100, 1000000007ULL));
}
```

**输出：**

```
3^13 = 1594323
2^100 mod 1e9+7 = 976371285
```

**复杂度：** O(log n)，比朴素 O(n) 快得多。`2^100` 只需约 7 次循环。

**顺着这个思路还能写快速乘（防止乘法溢出）：**

```cpp
u64 mul_mod(u64 a, u64 b, u64 mod) {   // 龟速乘，O(log b)，不溢出
    u64 r = 0; a %= mod;
    while (b) { if (b & 1) r = (r + a) % mod; a = (a << 1) % mod; b >>= 1; }
    return r;
}
```

### 案例 7：位图去重 + 排序（40 亿数据判重）

```cpp
#include <bit>
#include <cstdint>
#include <cstdio>
#include <vector>
using u64 = std::uint64_t;

int main() {
    std::vector<int> data = {7, 3, 7, 9, 1, 3, 12, 1};
    u64 bm = 0;
    for (int v : data) bm |= (1ULL << v);      // 存在就把对应位点亮

    printf("原数据: "); for (int v : data) printf("%d ", v); printf("\n");
    printf("去重排序后: ");
    for (int i = 0; i < 64; ++i) if ((bm >> i) & 1ULL) printf("%d ", i);
    printf("\n元素个数 = %d, 含9? %d\n", (int)std::popcount(bm), (int)((bm >> 9) & 1ULL));
}
```

**输出：**

```
原数据: 7 3 7 9 1 3 12 1 
去重排序后: 1 3 7 9 12 
元素个数 = 5, 含9? 1
```

**为什么经典：** 40 亿个 `[0, 2^32)` 范围内的不重复整数，用 `bool` 数组要 4 GB，用位图只需 **512 MB**（`2^32 bit = 4G bit = 512 MB`），且插入、查询都是 O(1)。

**可扩展版本（任意上限）：**

```cpp
class Bitmap {
    std::vector<u64> bits;
public:
    Bitmap(size_t n) : bits((n + 63) / 64, 0) {}
    void set(size_t i)   { bits[i >> 6] |=  (1ULL << (i & 63)); }
    void clear(size_t i) { bits[i >> 6] &= ~(1ULL << (i & 63)); }
    bool test(size_t i) const { return (bits[i >> 6] >> (i & 63)) & 1ULL; }
};
```

> `i >> 6` 等价于 `i / 64`，`i & 63` 等价于 `i % 64`，配合 64 分块时这样写最快。

### 案例 8：子集枚举（状态压缩基础）

```cpp
#include <cstdio>
int main() {
    int nums[] = {3, 1, 4}, n = 3;
    for (int s = 0; s < (1 << n); ++s) {          // s 就是一个子集
        int sum = 0;
        printf("子集 {");
        for (int i = 0; i < n; ++i)
            if (s >> i & 1) { sum += nums[i]; printf("%d ", nums[i]); }
        printf("} sum=%d\n", sum);
    }

    // 只枚举某个 mask 的子集（O(3^n) 的枚举子集技巧）
    unsigned m = 0b101100u;
    printf("\nmask=101100 的子集: ");
    for (unsigned s = m; ; s = (s - 1) & m) {
        printf("%u ", s);
        if (s == 0) break;                        // s 为 0 时必须手动退出（unsigned 下溢）
    }
    putchar('\n');
}
```

**输出：**

```
子集 {} sum=0
子集 {3 } sum=3
子集 {1 } sum=1
子集 {3 1 } sum=4
子集 {4 } sum=4
子集 {3 4 } sum=7
子集 {1 4 } sum=5
子集 {3 1 4 } sum=8

mask=101100 的子集: 44 40 36 32 12 8 4 0 
```

**关键技巧：** `s = (s - 1) & m` 能生成 `m` 的所有子集，且不重不漏。**必须把循环变量声明为无符号并检查 `s == 0` 后 break**，否则 `unsigned` 从 0 减 1 会绕回最大值导致死循环。

### 案例 9：位反转（32 位，分治交换）

```cpp
#include <cstdint>
#include <cstdio>
using u32 = std::uint32_t;

u32 rev32(u32 x) {                       // 相邻交换 → 2位交换 → 4位 → 8位 → 16位
    x = ((x & 0x55555555u) << 1) | ((x >> 1) & 0x55555555u);
    x = ((x & 0x33333333u) << 2) | ((x >> 2) & 0x33333333u);
    x = ((x & 0x0F0F0F0Fu) << 4) | ((x >> 4) & 0x0F0F0F0Fu);
    x = ((x & 0x00FF00FFu) << 8) | ((x >> 8) & 0x00FF00FFu);
    return (x << 16) | (x >> 16);
}

void bin32(u32 x) { for (int i = 31; i >= 0; --i) putchar((x >> i) & 1u ? '1' : '0'); }

int main() {
    u32 v = 0b1011u;
    printf("in : "); bin32(v); printf("\nout: "); bin32(rev32(v));
    printf(" = %u\n", rev32(v));
}
```

**输出：**

```
in : 00000000000000000000000000001011
out: 11010000000000000000000000000000 = 3489660928
```

**应用：** FFT 蝶形运算的位反转置换（bit-reversal permutation）、大小端转换、CRC 计算。

**魔术数字含义：** `0x55 = 0101...`（间隔 1 位）、`0x33 = 0011...`（间隔 2 位）、`0x0F = 00001111`（间隔 4 位），逐级扩大交换跨度。

### 案例 10：格雷码（相邻编码只差 1 位）

```cpp
#include <cstdint>
#include <cstdio>
using u32 = std::uint32_t;

u32 to_gray(u32 n) { return n ^ (n >> 1); }        // 二进制 → 格雷码

u32 from_gray(u32 g) {                              // 格雷码 → 二进制
    g ^= g >> 16; g ^= g >> 8; g ^= g >> 4; g ^= g >> 2; g ^= g >> 1;
    return g;
}

int main() {
    for (u32 i = 0; i < 8; ++i)
        printf("bin=%u gray=%u (逆变换回 %u)\n", i, to_gray(i), from_gray(to_gray(i)));
}
```

**输出：**

```
bin=0 gray=0 (逆变换回 0)
bin=1 gray=1 (逆变换回 1)
bin=2 gray=3 (逆变换回 2)
bin=3 gray=2 (逆变换回 3)
bin=4 gray=6 (逆变换回 4)
bin=5 gray=7 (逆变换回 5)
bin=6 gray=5 (逆变换回 6)
bin=7 gray=4 (逆变换回 7)
```

**为什么重要：** 格雷码相邻两个数的二进制**只有一位不同**。机械编码器、ADC 采样用它，可以避免多位同时跳变时因信号不同步产生的毛刺（比如 `0111→1000` 四位全变，中间可能读到 `0110`、`0100` 等错误值）。

### 案例 11：字符处理技巧

```cpp
#include <cstdio>
int main() {
    printf("'a' ^ ' ' = '%c'\n", 'a' ^ ' ');      // 大小写互转（0x20）
    printf("'A' | 0x20 = '%c'\n", 'A' | 0x20);    // 强制转小写
    printf("'d' & ~0x20 = '%c'\n", 'd' & ~0x20);  // 强制转大写
    printf("'7' & 0x0F = %d\n", '7' & 0x0F);      // 字符转数字
}
```

**输出：**

```
'a' ^ ' ' = 'A'
'A' | 0x20 = 'a'
'd' & ~0x20 = 'D'
'7' & 0x0F = 7
```

**原理：** ASCII 中 `'a'=97=0b1100001`，`'A'=65=0b1000001`，只差第 5 位（值 32 = `' '` 空格字符的 ASCII）。

⚠️ **只对 ASCII 有效**，处理 UTF-8 中文请用 `<locale>` 或 ICU 库。

### 案例 12：汉明距离、无临时变量交换、位运算取绝对值

```cpp
#include <bit>
#include <cstdio>

int main() {
    // 汉明距离：两数不同位的个数
    printf("hamming(0b1101, 0b1011) = %d\n", (int)std::popcount(0b1101u ^ 0b1011u));

    // 无临时变量交换（注意：a 和 b 不能是同一个变量！）
    int p = 6, q = 9;
    p ^= q; q ^= p; p ^= q;
    printf("交换后 p=%d q=%d\n", p, q);

    // 位运算取绝对值
    auto iabs = [](int n) { int mask = n >> 31; return (n ^ mask) - mask; };
    printf("iabs(-42)=%d iabs(42)=%d\n", iabs(-42), iabs(42));
}
```

**输出：**

```
hamming(0b1101, 0b1011) = 2
交换后 p=9 q=6
iabs(-42)=42 iabs(42)=42
```

**绝对值原理：** `n` 为负数时 `n>>31` 得 `-1`（全 1），`n ^ -1 = ~n`，`~n - (-1) = ~n + 1 = -n` ✅；`n` 为非负时 `mask=0`，原样返回。

⚠️ **异或交换的坑：** `a[i] ^= a[j]` 当 `i == j` 时会把元素清零。生产代码请用 `std::swap`——编译器会优化，且异或交换破坏了编译器的依赖分析，实际往往更慢。

### 案例 13：状态压缩 DP —— 旅行商问题（TSP）

把“已访问城市集合”压成一个整数的经典范例。

```cpp
#include <algorithm>
#include <cstdio>
#include <vector>

int main() {
    const int N = 4, INF = 1e9;
    int dist[4][4] = {{0,2,9,10},{1,0,6,4},{15,7,0,8},{6,3,12,0}};

    // dp[mask][i] = 已访问集合为 mask、当前停在 i 的最短距离
    std::vector<std::vector<int>> dp(1 << N, std::vector<int>(N, INF));
    dp[1][0] = 0;                                  // 从城市 0 出发

    for (int s = 1; s < (1 << N); ++s)
        for (int i = 0; i < N; ++i) {
            if (dp[s][i] == INF) continue;
            for (int j = 0; j < N; ++j)
                if (!(s >> j & 1))                 // j 未访问
                    dp[s | (1 << j)][j] =
                        std::min(dp[s | (1 << j)][j], dp[s][i] + dist[i][j]);
        }

    int best = INF;
    for (int i = 1; i < N; ++i)                    // 回到起点 0
        best = std::min(best, dp[(1 << N) - 1][i] + dist[i][0]);
    printf("TSP 最短回路 = %d\n", best);
}
```

**输出：**

```
TSP 最短回路 = 21
```

**复杂度：** O(2^n · n²)，n ≤ 20 左右可用。状态数从 n! 降到 2^n，这就是位运算带来的质变。

### 案例 14：布隆过滤器（极简版）

```cpp
#include <cstdint>
#include <cstdio>
#include <string>
using u64 = std::uint64_t;

int main() {
    u64 bf = 0;                                    // 64 位位数组（演示用，真实场景大得多）

    auto h = [](const std::string& s, int k) {     // FNV 风格哈希 + 加盐
        u64 x = 1469598103934665603ULL;
        for (char ch : s) { x ^= (unsigned char)ch + k; x *= 1099511628211ULL; }
        return (int)(x & 63);
    };
    auto put = [&](const std::string& s) { for (int k = 0; k < 3; ++k) bf |= 1ULL << h(s, k); };
    auto has = [&](const std::string& s) {
        for (int k = 0; k < 3; ++k) if (!(bf >> h(s, k) & 1ULL)) return false;
        return true;
    };

    put("apple"); put("banana");
    printf("apple? %d  banana? %d  cherry? %d (可能误判)\n",
           has("apple"), has("banana"), has("cherry"));
}
```

**输出：**

```
apple? 1  banana? 1  cherry? 0 (可能误判)
```

**特性：** 说“不存在”一定准确（不会漏报），说“存在”可能有误判。位数组越大、哈希函数越多，误判率越低。

### 案例 15：运算符优先级陷阱（血的教训）

```cpp
#include <cstdio>
int main() {
    int flags = 0;
    printf("flags & 4 == 4 实际解析为 flags & (4==4) = %d\n", flags & 4 == 4);
    printf("正确写法 (flags & 4) == 4 = %d\n", (flags & 4) == 4);
    printf("1 << 2 + 1 = %d  (实为 1 << (2+1))\n", 1 << 2 + 1);
}
```

**输出（编译器会给出 `-Wparentheses` 警告）：**

```
flags & 4 == 4 实际解析为 flags & (4==4) = 0
正确写法 (flags & 4) == 4 = 0
1 << 2 + 1 = 8  (实为 1 << (2+1))
```

**这是位运算最高频的 bug。** 原因：`==`、`!=`、`<` 等比较运算符的优先级**高于** `&`、`^`、`|`，而 `+` 的优先级**高于** `<<`、`>>`。

**铁律：位运算表达式一律加括号。**


## 第 6 章 C++20 `<bit>` 标准库

C++20 终于把位操作标准化了，**不要再手写 `__builtin_popcount`**。

```cpp
#include <bit>
#include <cstdint>
#include <cstdio>
using u32 = std::uint32_t;

int main() {
    u32 x = 0b1011000u;
    printf("popcount=%d countr_zero=%d countl_zero=%d\n",
           (int)std::popcount(x), (int)std::countr_zero(x), (int)std::countl_zero(x));
    printf("bit_width=%d has_single_bit=%d bit_ceil=%d bit_floor=%d\n",
           (int)std::bit_width(x), (int)std::has_single_bit(x),
           (int)std::bit_ceil(x), (int)std::bit_floor(x));
    printf("rotl(0x80000001,1)=0x%08X\n", std::rotl(0x80000001u, 1));
}
```

**输出：**

```
popcount=3 countr_zero=3 countl_zero=25
bit_width=7 has_single_bit=0 bit_ceil=128 bit_floor=64
rotl(0x80000001,1)=0x00000003
```

### 完整函数表

| 函数 | 作用 | 等价手写实现 |
| --- | --- | --- |
| `std::popcount(x)` | 统计 1 的个数（汉明重量） | Kernighan 循环 |
| `std::has_single_bit(x)` | 是否为 2 的幂 | `x && !(x & (x-1))` |
| `std::bit_ceil(x)` | 向上取到最近的 2 的幂 | 手写易错 |
| `std::bit_floor(x)` | 向下取到最近的 2 的幂 | `1 << (bit_width-1)` |
| `std::bit_width(x)` | 表示 x 所需的最少位数 | `32 - clz(x)` |
| `std::countr_zero(x)` | 末尾连续 0 的个数（ctz） | `log2(lowbit)` |
| `std::countl_zero(x)` | 开头连续 0 的个数（clz） | |
| `std::countr_one(x)` / `countl_one(x)` | 连续 1 的个数 | |
| `std::rotl(x, s)` / `rotr(x, s)` | **循环**左移/右移（不丢位） | 哈希算法常用 |
| `std::endian::native` | 判断本机字节序 | 网络编程 |

⚠️ 注意：`std::popcount(0)` 返回 0，但 `std::countr_zero(0)` 返回**位宽**（如 32），使用前确认边界行为。


## 第 7 章 位域与 `std::bitset`

### 7.1 位域（bit-field）：结构体级别的位打包

```cpp
#include <cstdio>
struct Flags {
    unsigned read  : 1;      // 占 1 位
    unsigned write : 1;
    unsigned exec  : 1;
    unsigned level : 3;      // 占 3 位，取值 0~7
};

int main() {
    Flags f{1, 0, 1, 5};
    printf("sizeof=%zu read=%u write=%u exec=%u level=%u\n",
           sizeof(f), f.read, f.write, f.exec, f.level);
}
```

**输出：**

```
sizeof=4 read=1 write=0 exec=1 level=5
```

**优点：** 语法直观，内存紧凑（本例 4 个字段塞进 4 字节）。
**缺点（重要）：**
- **内存布局由编译器决定**，跨平台/跨编译器不保证一致 → 不能用于网络传输或持久化
- 位域成员**不能取地址**（`&f.read` 非法）
- 结构体总大小不一定等于位的总和（会有对齐填充）

**结论：** 协议解析请用显式移位掩码；仅在内存敏感且不跨平台的场景用位域。

### 7.2 `std::bitset`：任意长度的位集合

```cpp
#include <bitset>
#include <iostream>
int main() {
    std::bitset<8> a("10110010"), b("01101101");
    std::cout << "a      = " << a << "\n"
              << "a & b  = " << (a & b) << "\n"
              << "a | b  = " << (a | b) << "\n"
              << "a ^ b  = " << (a ^ b) << "\n"
              << "~a     = " << (~a) << "\n"
              << "a << 2 = " << (a << 2) << "\n"
              << "count  = " << a.count() << "\n"      // 1 的个数
              << "any/anyOf: " << a.any() << a.all() << a.none() << "\n"
              << "a[1]   = " << a[1] << "\n";
}
```

特点：大小**编译期固定**，支持 `& | ^ ~ << >>` 和 `count/any/all/none/set/reset/flip/test`。运行期动态长度请用 `boost::dynamic_bitset` 或 `vector<uint64_t>`。


## 第 8 章 陷阱、未定义行为与最佳实践

### 8.1 十大坑位清单

| # | 陷阱 | 错误写法 | 正确写法 |
| --- | --- | --- | --- |
| 1 | **优先级** | `if (flags & MASK == 0)` | `if ((flags & MASK) == 0)` |
| 2 | **移位数越界**（UB） | `x << 32`（32 位类型） | 移位数必须 `< 位宽` |
| 3 | **有符号数左移溢出**（UB） | `int(1) << 31` | `1u << 31` |
| 4 | **有符号数右移**是实现定义 | `int(-8) >> 1` | 改用 `uint32_t` |
| 5 | **负移位数**（UB） | `x << -1` | 移位数用无符号 |
| 6 | **类型宽度不足** | `1 << 40` | `1ULL << 40` |
| 7 | **`~` 污染高位** | `x & ~1`（可能非预期） | `x & ~1u`，明确类型 |
| 8 | **整数提升** | `uint8_t a; ~a` 变成 int | 显式 cast 回 `uint8_t` |
| 9 | **`char` 符号未定义** | `char c; c >> 1` | 用 `unsigned char` |
| 10 | **异或交换自身清零** | `a ^= a` | 用 `std::swap` |

### 8.2 整数提升陷阱（很隐蔽）

```cpp
uint8_t a = 0xFF;
uint8_t b = ~a;        // ~a 先提升为 int → 0xFFFFFF00，截断后 b = 0x00（不是你想要的 0x00？）
// 实际上 b == 0x00，因为 ~0xFF = 0xFFFFFF00，取低 8 位 = 0x00
printf("%u\n", (unsigned)~a);   // 输出 4294967040，不是 255！
```

**解法：做完位运算立即 cast 回目标类型。**

### 8.3 有符号 vs 无符号混用

```cpp
int a = -1;
unsigned b = 1;
if (a < b) { /* 不会执行！*/ }  // a 被转换为 unsigned，变成 4294967295
```

`-Wall -Wextra -Wconversion` 能捕获大部分这类问题，**建议开启 `-Wsign-conversion`**。

### 8.4 字节序（Endianness）与位序无关

注意区分：**位运算不受字节序影响**（`x >> 1` 永远是逻辑上的除以 2），但**内存中的字节排列受影响**。网络传输需 `htonl/ntohl`。


## 第 9 章 性能与可读性

### 9.1 编译器比你想象的聪明

```cpp
x * 2      // 编译器会自动优化为 x << 1
x % 8      // 若 x 无符号，优化为 x & 7
x / 4      // 优化为 x >> 2
```

**所以：不要为了“性能”把 `x * 2` 改成 `x << 1`，可读性更重要。** 位运算的价值在于**表达意图**（位掩码、集合操作），而不是当算术运算符的替代品。

### 9.2 什么时候位运算真的更快

| 场景 | 提速来源 |
| --- | --- |
| `x & (n-1)` 替代 `x % n` | 取模指令约 20+ 周期，AND 约 1 周期 |
| `std::popcount` | 单条 `popcnt` 硬件指令 |
| 位图代替 `bool[]` | 缓存命中率提升 64 倍 |
| 状态压缩 DP | 用 `int` 作哈希键，避免 `vector<bool>` 开销 |
| 无分支写法 | 消除分支预测失败的 ~20 周期惩罚 |

### 9.3 可读性建议

```cpp
// ❌ 魔法数字满天飞
if ((x & 0x2A) == 0x22) { ... }

// ✅ 命名常量 + 语义化函数
constexpr uint32_t FLAG_READY   = 1u << 1;
constexpr uint32_t FLAG_LOCKED  = 1u << 3;
constexpr uint32_t FLAG_INVALID = 1u << 5;

[[nodiscard]] constexpr bool is_ready(uint32_t f) noexcept {
    return (f & FLAG_READY) != 0;
}
```

用 `constexpr` + `enum class` + `[[nodiscard]]`，把位运算封装成**有名字的语义**，这是生产代码与竞赛代码最大的区别。

```cpp
vector<int> singleNumber(vector<int>& nums) {
    unsigned xorsum = 0;
    for (int x : nums) xorsum ^= (unsigned)x;
    unsigned lowbit = xorsum & (~xorsum + 1);   // 取最低位的 1
    int a = 0, b = 0;
    for (int x : nums) {
        if ((unsigned)x & lowbit) a ^= x;       // 分为两组
        else                      b ^= x;
    }
    return {a, b};
}
```

```cpp
    return right;                               // 直到 right <= left
}
```

### 17.2 线性基（竞赛向）

**线性基**是处理异或最大和/最小和问题的核心工具，本质是用一组基向量张成原数组的异或空间。

```cpp
class XorBasis {
    static constexpr int N = 31;   // 值域 <= 2^31
    int b[N]{};
public:
    void insert(int x) {
        for (int i = N - 1; i >= 0; --i) {
            if (!(x >> i)) continue;
            if (!b[i]) { b[i] = x; return; }
            x ^= b[i];
        }
    }
    int max_xor() const {
        int res = 0;
        for (int i = N - 1; i >= 0; --i)
            if ((res ^ b[i]) > res) res ^= b[i];
        return res;
    }
    int min_xor() const {
        for (int i = 0; i < N; ++i)
            if (b[i]) return b[i];
        return 0;
    }
};
```

> 线性基相关 LeetCode 题较少，主要出现在竞赛中。核心应用：最大异或子集和、最小异或子集和、第 k 大异或和。

### 19.2 刷题建议

1. **按模式刷，不按题号刷。** 位运算题的核心是模式识别——看到“只出现一次”就想到异或，看到“子集”就想到位掩码，看到“范围与”就想到公共前缀。

2. **先自己想 10 分钟再看题解。** 位运算题的特点是一旦想到就很简单，想不到了解思路后要能默写。

3. **手算验证。** 拿几个小数字（如 5、6、7）在纸上写出二进制，手动模拟位运算过程，比盯着代码看有效得多。

## 第 20 章 一页速查表

### 运算符

```
&   与：全 1 才 1      →  提取、屏蔽、判奇偶
|   或：有 1 就 1      →  组合、置位
^   异或：不同才 1     →  翻转、消元、交换
~   取反：0↔1          →  构造反掩码
<<  左移：低位补 0     →  ×2^n、造掩码
>>  右移：补 0/符号位  →  ÷2^n、取字段
```

### 一行代码技巧

```cpp
(x >> k) & 1              // 读第 k 位
x | (1 << k)              // 置第 k 位 = 1
x & ~(1 << k)             // 置第 k 位 = 0
x ^ (1 << k)              // 翻转第 k 位
x & (x - 1)               // 清掉最低位的 1
x & -x                    // 只保留最低位的 1（lowbit）
x & (x - 1) == 0          // 是否为 2 的幂（且 x != 0）
x & 1                     // 奇偶性
x & (n - 1)               // x % n（n 为 2 的幂）
(x >> 6, x & 63)          // 位图中的块号与块内偏移
n ^ (n >> 1)              // 转格雷码
c ^ 0x20                  // 字母大小写互转
c & 0x0F                  // '0'~'9' 转数字
mask = n >> 31; (n^mask)-mask   // 取绝对值
```

### 常用子集枚举模板

```cpp
// 枚举所有子集
for (int s = 0; s < (1 << n); ++s) { /* ... */ }

// 枚举 mask 的所有子集（不重不漏）
for (unsigned s = mask; ; s = (s - 1) & mask) {
    /* 处理子集 s */
    if (s == 0) break;
}

// 状态压缩 DP 典型框架
vector<int> dp(1 << n, INF);
dp[0] = 0;
for (int mask = 0; mask < (1 << n); ++mask)
    for (int i = 0; i < n; ++i) {
        if (!(mask >> i & 1)) continue;
        dp[mask] = min(dp[mask], dp[mask ^ (1 << i)] + cost[i]);
    }
```
