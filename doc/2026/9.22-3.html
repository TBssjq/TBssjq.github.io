C++ 那些「奇怪却短得离谱」的算法

收录标准：代码量 ≤ 10 行，但第一次看见时会让人怀疑人生——"这也能行？" 从位运算黑魔法、玄学浮点 Hack，到短到 6 行的并查集，再到纯属整活的奇葩排序。

本文所有代码片段均在 g++ 11.4 / -std=c++20 -O2 下编译并跑过正确性验证（含随机对拍与暴力对拍），可以直接抄。 凡是"看起来对但有坑"的地方都标了 ⚠️。

一、位运算黑魔法（Bit Twiddling）

1. x & -x：取出最低位的那个 1

int lowbit(int x) { return x & -x; }   // 12(1100) -> 4(0100)

补码下 -x == ~x + 1，它会把最低位 1 以下全部置 0、以上全部取反，一按与就只剩那一个 1。 树状数组、状压 DP、枚举子集的骨架全靠它。

⚠️ x == INT_MIN 时 -x 溢出，是 UB。要稳妥就用 unsigned： uint32_t lowbit(uint32_t x) { return x & -x; }

2. x & (x - 1)：抹掉最低位的 1

bool isPow2(unsigned x) { return x && !(x & (x - 1)); }        // 是不是 2 的幂
int  popcount(int x) { int c = 0; while (x) { x &= x - 1; ++c; } return c; }  // Brian Kernighan

popcount 的循环次数 = 1 的个数，而不是位数，比逐位扫描快得多。 生产环境直接用 __builtin_popcount(x)（通常编译成一条 popcnt 指令）。

3. 异或三连：找只出现一次的数

int singleNumber(const vector<int>& a) {
    int ans = 0;
    for (int v : a) ans ^= v;   // a^a=0, 0^x=x, 满足交换律
    return ans;
}

O(n) 时间、O(1) 空间。前提是其余元素都恰好出现两次。 若其余元素出现三次，改用"逐位模 3 求和"或状态机（代码会长一点，就不算"短"了）。

⚠️ 别用 a ^= b ^= a ^= b 做交换：同一表达式内对 a 多次修改且无顺序保证，是未定义行为，而且编译器生成的代码通常比 std::swap 更慢、还不能用于同一对象（swap(x, x) 会把 x 清零）。

4. 无分支绝对值 / min / max

int32_t iabs(int32_t x) { int32_t m = x >> 31; return (x ^ m) - m; }
int imin(int a, int b)  { return b ^ ((a ^ b) & -(a < b)); }
int imax(int a, int b)  { return a ^ ((a ^ b) & -(a < b)); }
int signum(int x)       { return (x > 0) - (x < 0); }          // -1 / 0 / 1
bool opposite(int a, int b) { return (a ^ b) < 0; }            // 是否异号

原理是"用掩码做条件传送"：-(a < b) 得到全 1 或全 0，再用异或选择。 在分支预测失败率极高的场合（随机数据的最值扫描）确实能提速。

⚠️ iabs(INT32_MIN) 溢出 UB；C++20 才正式规定有符号右移为算术右移，之前的编译器虽然都这么做，但严格讲是实现定义。

5. 防溢出取平均

int avg(int a, int b) { return (a & b) + ((a ^ b) >> 1); }     // (INT_MAX+INT_MAX)/2 不会炸

(a + b) / 2 在 a + b 溢出时是 UB，二分查找里 mid = (l + r) / 2 的经典 bug 就出自这里。

⚠️ 这个位运算版本算的是 floor 平均（向负无穷取整），而 (a + b) / 2 是向零取整，奇数负和时两者差 1： avg(INT_MAX, INT_MIN) == -1，而 (INT_MAX + INT_MIN) / 2 == 0。 保守写法其实更简单：l + (r - l) / 2。

6. 只用位运算做加法

int add(int a, int b) {
    while (b) {
        uint32_t carry = ((uint32_t)a & (uint32_t)b) << 1;   // 进位
        a ^= b;                                              // 不进位相加
        b = (int)carry;
    }
    return a;
}

CPU 里加法器就是这么搭的。典型用途：某些只允许用 + 的面试题、或用位运算实现减法/乘法。 ⚠️ 中途必须用无符号类型承载进位，否则溢出 UB。

7. 格雷码与逆变换

unsigned gray(unsigned n)   { return n ^ (n >> 1); }                    // 二进制 -> 格雷码
unsigned invgray(unsigned g){ unsigned n = 0; while (g) { n ^= g; g >>= 1; } return n; }  // 逆

相邻整数只差一位——旋转编码器、卡诺图、汉密尔顿路径都用它。 逆变换本质是"前缀异或"。

8. 枚举子集：一行 for

for (int s = m; ; s = (s - 1) & m) {   // 遍历 m 的所有子集（含空集）
    /* ... */
    if (s == 0) break;
}

(s - 1) & m 会自动借位并"跳过"不属于 m 的位，绝不产生非法子集，比逐个 if ((s & m) == s) 快得多。 对 m = 0b1011（3 个 1）恰好访问 8 个子集。

9. Gosper's Hack：枚举"恰好 k 个 1"的下一个数

uint32_t gosper(uint32_t x) {            // 返回 popcount 相同、字典序的下一个数
    uint32_t c = x & -x, r = x + c;
    return (((r ^ x) >> 2) / c) | r;
}

想枚举"n 个里选 k 个"的全部组合（不想要 k 的循环嵌套），就用它： 从 (1u << k) - 1 开始反复调用，直到 x >= (1u << n)。 已对拍验证：对 3 ≤ n ≤ 12 的所有 k，生成的组合数量与 C(n,k) 完全一致且无重复。

10. 32 位整数位反转（分治魔法）

uint32_t rev32(uint32_t x) {
    x = ((x & 0x55555555u) << 1) | ((x >> 1) & 0x55555555u);   // 相邻 1 位对调
    x = ((x & 0x33333333u) << 2) | ((x >> 2) & 0x33333333u);   // 相邻 2 位对调
    x = ((x & 0x0F0F0F0Fu) << 4) | ((x >> 4) & 0x0F0F0F0Fu);   // 4 位
    x = ((x & 0x00FF00FFu) << 8) | ((x >> 8) & 0x00FF00FFu);   // 8 位
    return (x << 16) | (x >> 16);                              // 16 位
}

5 步就把 32 位翻转，比循环 32 次快一个数量级。FFT 位反转置换、二进制回文判断都用得上。

11. 向上取整到 2 的幂

uint32_t npot(uint32_t x) { --x; x |= x >> 1; x |= x >> 2; x |= x >> 4; x |= x >> 8; x |= x >> 16; return x + 1; }

先把最高位 1 右边全部"糊"成 1，再加 1 进位——像滚雪球一样，5 次移位覆盖 32 位。 环形缓冲区、哈希表容量、内存对齐的常客。⚠️ x == 0 时返回 0，需要单独处理。

12. 编译器内建指令（一行顶十行）

__builtin_clz(x)        // 前导零个数 -> 最高位 1 的位置 = 31 - __builtin_clz(x)
__builtin_ctz(x)        // 尾随零个数 -> lowbit 的指数
__builtin_popcount(x)   // 1 的个数（C++20 也有 std::popcount）
__builtin_parity(x)     // 1 的个数的奇偶
uint32_t hi = 1u << (31 - __builtin_clz(x));   // 只保留最高位的 1
uint32_t rotl(uint32_t x, int k) { return (x << k) | (x >> (32 - k)); }  // 循环左移

⚠️ clz/ctz 对 0 的结果未定义，调用前判空。MSVC 要换成 _BitScanReverse / std::countr_zero。

二、玄学数值 Hack

13. 快速平方根倒数：0x5f3759df

#include <bit>
float rsqrt(float x) {                       // C++20 安全写法
    int32_t i = std::bit_cast<int32_t>(x);   // 把浮点位型当整数看
    i = 0x5f3759df - (i >> 1);               // 魔法数字：一次「除以 2 再取负」的近似
    float y = std::bit_cast<float>(i);
    return y * (1.5f - 0.5f * x * y * y);    // 一步牛顿迭代
}

因《雷神之锤 III》源码注释里那句 // what the fuck? 而闻名。 原理：浮点位型右移一位 ≈ 指数减半；那个魔法常数同时修正了指数偏移与尾数误差。

实测（x 取 0.01 ~ 2000，20 万个采样点的最大相对误差）：

牛顿迭代次数 最大相对误差
0 次（纯魔法） 3.44%
1 次 0.175%
2 次 0.00047%

⚠️ 三点：① 老代码 i = *(long*)&y 违反 strict aliasing，是 UB，且 long 在 64 位 Linux 是 8 字节（经典 bug），务必用 bit_cast 或 memcpy；② 现代 CPU 的 rsqrtss 指令更快更准，这个 Hack 现在主要是"文物价值"；③ 想更准一点可换 Chris Lomont 推导的 0x5f375a86。

14. 牛顿迭代开平方（含小数也稳）

double sqrt_newton(double n) { double x = n; for (int i = 0; i < 60; ++i) x = (x + n / x) / 2; return x; }

迭代 60 次已达 double 精度极限（实际 5~6 次就够）。不能用地递归、不需要任何库的"手搓 sqrt"。

15. xorshift32：三行一个随机数发生器

uint32_t x = 2463534242u;                      // 种子，不能为 0
uint32_t xorshift32() { x ^= x << 13; x ^= x >> 17; x ^= x << 5; return x; }

比你想象的靠谱：周期长达 2³²−1。已验证——连续生成 200 万个输出无任何重复，均值 0.500，低位无明显自相关。

⚠️ 只是"统计上还行"，绝不能用于密码学（状态可线性还原）；正式项目请用 std::mt19937。

16. 6k ± 1 判素数

bool isPrime(int n) {
    if (n < 2) return false;
    if (n % 2 == 0 || n % 3 == 0) return n == 2 || n == 3;
    for (int i = 5; 1LL * i * i <= n; i += 6)
        if (n % i == 0 || n % (i + 2) == 0) return false;   // 只测 6k-1 和 6k+1
    return true;
}

除了 2 和 3，所有素数都形如 6k ± 1，试除量直接砍到 1/3。单次判定 O(√n / 3)。

17. 快速幂（二进制幂）

long long qpow(long long a, long long n) {          // a^n
    long long r = 1;
    while (n) { if (n & 1) r *= a; a *= a; n >>= 1; }
    return r;
}
long long qpowm(long long a, long long n, long long m) {   // a^n mod m
    long long r = 1 % m; a %= m;
    while (n) { if (n & 1) r = (__int128)r * a % m; a = (__int128)a * a % m; n >>= 1; }
    return r;
}

O(log n)。取模版用 __int128 防乘法溢出，是竞赛里的保命写法。

18. 一行 gcd

int gcd(int a, int b) { return b ? gcd(b, a % b) : a; }
int lcm(int a, int b) { return a / gcd(a, b) * b; }   // 先除后乘，防溢出

欧几里得算法，O(log min(a,b))，可能是世界上最短的"非平凡"递归算法。

19. 蒙特卡洛求 π

std::mt19937 rng(std::random_device{}());
std::uniform_real_distribution<double> U(0, 1);
long in = 0, N = 10'000'000;
for (long i = 0; i < N; ++i) { double x = U(rng), y = U(rng); if (x*x + y*y < 1) ++in; }
double pi = 4.0 * in / N;      // 误差 ≈ 1/√N，1e7 次大约到 3.141x

"用随机性对抗维度"的最小范例。精度随 √N 增长，慢得离谱但代码只有 4 行。

20. Szudzik 配对函数：二维压一维

uint64_t pair(uint32_t a, uint32_t b) { return a >= b ? (uint64_t)a * a + a + b : (uint64_t)a + (uint64_t)b * b; }

把 N×N 的双射塞进 N² 个整数里（比康托展开更紧凑）。已验证在 300×300 范围内完全无碰撞。 用途：把二元组当 unordered_set 的 key，而不必写自定义哈希。

三、短到离谱的正经算法

21. Floyd 判圈（龟兔赛跑）

bool hasCycle(Node* h) {
    Node *slow = h, *fast = h;
    while (fast && fast->next) {
        slow = slow->next; fast = fast->next->next;
        if (slow == fast) return true;
    }
    return false;
}

O(1) 空间判断链表是否有环——不用哈希表。想找环入口：相遇后把 slow 放回 h，两者同速再走，相遇点即入口。

22. Boyer-Moore 多数投票

int majority(const vector<int>& a) {
    int cand = 0, cnt = 0;
    for (int v : a) { if (!cnt) cand = v; cnt += (v == cand) ? 1 : -1; }
    return cand;   // 存在"出现次数 > n/2"的元素时，答案就是它
}

O(n) 时间、O(1) 空间，"对消"思想。⚠️ 前提是不存在多数元素时结果无意义，必须再遍历一次做校验。

23. Fisher-Yates 洗牌

for (int i = n - 1; i > 0; --i) std::swap(a[i], a[std::uniform_int_distribution<int>(0, i)(rng)]);

两行、均匀、无偏。已验证：n=4 时 24 种排列全部出现且频率均衡。

⚠️ 两个致命错误：① 用 rand() % (i + 1) 会有取模偏差，且 rand() 质量差；② 写成 % n 而不是 % (i+1) 会得到有偏的排列。生产代码直接用 std::shuffle(a.begin(), a.end(), rng)。

24. 约瑟夫环：一行递推

int josephus(int n, int m) { int f = 0; for (int i = 1; i <= n; ++i) f = (f + m) % i; return f; }  // 0 下标

O(n)。f(n) = (f(n-1) + m) % n 从 1 人推到 n 人。已与暴力模拟对拍（n≤40, m≤12）全部吻合。 下标从 1 开始就 +1。

25. 树状数组（Fenwick Tree）

struct BIT {
    int n; vector<long long> t;
    BIT(int n) : n(n), t(n + 1, 0) {}
    void add(int i, long long v) { for (; i <= n; i += i & -i) t[i] += v; }
    long long sum(int i) { long long s = 0; for (; i > 0; i -= i & -i) s += t[i]; return s; }
    long long range(int l, int r) { return sum(r) - sum(l - 1); }
};

前缀和 + 单点修改，两个循环各 3 行。区间和：sum(r) - sum(l-1)。

26. 并查集：路径压缩 + 按秩合并

struct DSU {
    vector<int> p, r;
    DSU(int n) : p(n), r(n, 0) { std::iota(p.begin(), p.end(), 0); }
    int find(int x) { return p[x] == x ? x : p[x] = find(p[x]); }
    void unite(int a, int b) {
        if ((a = find(a)) == (b = find(b))) return;
        if (r[a] < r[b]) std::swap(a, b);
        p[b] = a; if (r[a] == r[b]) ++r[a];
    }
};

find 一行，unite 三行，均摊复杂度反阿克曼——实际就是 O(1)。已用 BFS 连通性对拍验证。

27. 埃氏筛

vector<bool> is(n + 1, true); is[0] = is[1] = false;
for (int i = 2; 1LL * i * i <= n; ++i)
    if (is[i]) for (long long j = 1LL * i * i; j <= n; j += i) is[j] = false;

O(n log log n)。两个细节：从 i*i 开始划（更小的倍数早被划掉了）、1LL*i*i 防溢出。 实测 n = 100000 恰好筛出 9592 个素数。

28. 原地反转链表（4 行）

Node *pre = nullptr, *cur = head;
while (cur) { Node* nx = cur->next; cur->next = pre; pre = cur; cur = nx; }
head = pre;

快慢指针找中点同理：while (f && f->next) { s = s->next; f = f->next->next; }。

29. 三分查找（单峰极值）

double l = -1e9, r = 1e9;
for (int i = 0; i < 100; ++i) {
    double m1 = l + (r - l) / 3, m2 = r - (r - l) / 3;
    if (f(m1) < f(m2)) l = m1; else r = m2;      // 求最大值；求最小值把 < 换成 >
}
printf("%.10f\n", (l + r) / 2);

固定 100 次迭代就能把区间压到 1e-19 量级，不用管精度阈值。 已验证：对 f(x) = -(x-3.7)² + 10，结果 3.7000000000。⚠️ 必须严格单峰，否则会跑到错的峰上。

30. 异或链表：省掉一半指针

struct XNode { int val; uintptr_t both; };        // both = prev ^ next
XNode* nextOf(XNode* cur, XNode* prev) {
    return reinterpret_cast<XNode*>(cur->both ^ reinterpret_cast<uintptr_t>(prev));
}

双向链表只存一个"异或指针"，靠 a ^ (a ^ b) == b 走回去。内存省 50%。

⚠️ 代价巨大：调试器看不了、GC 类语言没法用、一个节点地址变了整条链就废、现代 CPU 上分支预测和缓存表现更差。知道它存在即可，别写进项目。

31. 汉诺塔：3 行递归

void hanoi(int n, char a, char b, char c) {
    if (!n) return;
    hanoi(n - 1, a, c, b); printf("%c -> %c\n", a, c); hanoi(n - 1, b, a, c);
}

递归之美的最小样本：把"移动 n 个"分解成"移动 n-1 个"两次 + 中间一步。移动次数必为 2ⁿ−1。

32. 编译期计算（constexpr 一行）

constexpr long long fib(int n) { return n <= 1 ? n : fib(n - 1) + fib(n - 2); }
static_assert(fib(90) == 2880067194370816120LL);    // 编译期算完，运行时零开销

把"奇怪"从位运算挪到编译期：递归在编译器里跑，运行期只剩一个常量。 同理可写 constexpr 阶乘、素数判定表（配合循环可生成编译期查找表）。

33. 一行打印二进制

std::cout << std::bitset<32>(x) << '\n';      // 00000000000000000000000000001100

调试位运算时最省事的写法，比手写循环强。

四、整活专区：奇葩排序

这一节的算法都不该出现在生产代码里，但它们是理解"复杂度"这个概念最好的反面教材。以下四个均已对拍验证：随机数组排序结果正确。

34. Sleep Sort：让数字自己睡醒

std::vector<std::thread> ts;
for (int v : a) ts.emplace_back([v] {
    std::this_thread::sleep_for(std::chrono::milliseconds(v));
    std::cout << v << ' ';
});
for (auto& t : ts) t.join();

每个数睡 v 毫秒，小的先醒，于是"排好序了"。复杂度是……O(睡觉时间)？

⚠️ 只能排正整数、值大了要等半天、线程调度不保证顺序、结果不确定、负数直接异常。纯整活。

35. Bogo Sort：洗到对为止

while (!std::is_sorted(a.begin(), a.end()))
    std::shuffle(a.begin(), a.end(), rng);

期望时间 O(n · n!)，n=10 就要平均几百万次洗牌，n=20 基本等到宇宙热寂。 它的唯一价值：作为"随机算法期望复杂度"的教具。

36. Stooge Sort：递归砍三段，砍完还砍

void stooge(vector<int>& a, int l, int r) {
    if (a[l] > a[r]) std::swap(a[l], a[r]);
    if (r - l + 1 > 2) {
        int t = (r - l + 1) / 3;
        stooge(a, l, r - t); stooge(a, l + t, r); stooge(a, l, r - t);   // 前 2/3、后 2/3、再前 2/3
    }
}

复杂度 O(n^2.71)——比冒泡还慢，却是个正经的分治算法。看着它你就会明白：分治不等于快。

37. Slow Sort：投降乘法（Multiply and Surrender）

void slowsort(vector<int>& a, int i, int j) {
    if (i >= j) return;
    int m = (i + j) / 2;
    slowsort(a, i, m); slowsort(a, m + 1, j);
    if (a[m] > a[j]) std::swap(a[m], a[j]);
    slowsort(a, i, j - 1);          // 排好了? 再排一遍前 j-1 个
}

号称"故意设计成最烂的分治"：O(n^(log n / 2 + ...))，比 Stooge 还慢，却能证明正确。

38. Gnome Sort：一个下标来回走

void gnome(vector<int>& a) {
    int i = 1, n = a.size();
    while (i < n) {
        if (i == 0 || a[i - 1] <= a[i]) ++i;
        else { std::swap(a[i], a[i - 1]); --i; }      // 走错了就往回退
    }
}

O(n²) 但只要一个 int i，号称"最省内存的排序"（花匠挪花盆的既视感）。 有意思的是：把 i 的回退路径改成跳跃，它就变成了插入排序。

六、什么时候不该用这些

  1. 先问编译器，再问技巧。 -O2 下 GCC/Clang 会把 x / 2 变成移位、把简单的 min/max 变成 cmov、把 popcount 变成一条指令。手写 Hack 很可能只是让代码更难读，速度毫无变化，甚至更慢（异或交换就是典型）。
  2. 未定义行为是隐形炸弹。 *(float*)&i、有符号溢出、a ^= b ^= a ^= b、x >> 31 依赖实现——同一个二进制在 -O0 下对、-O3 下错的故事每天都在发生。需要位型转换时用 std::bit_cast（C++20）或 memcpy。
  3. 可移植性自己兜底。 __builtin_* 是 GCC/Clang 扩展，MSVC 另有其道；int 不一定是 32 位。写位运算就用 <cstdint> 的 int32_t / uint32_t。
  4. 精度与前提要写进注释。 快速平方根倒数只在 float 上成立；Boyer-Moore 必须二次校验；三分查找必须严格单峰；xorshift 不能用于安全场景。
  5. 可读性 > 炫技。 生产代码里 <algorithm> 的 std::shuffle / std::lower_bound / std::gcd（C++17）永远优先于手写版本。这些 Hack 的最佳归宿是：竞赛、底层库、以及你向同事解释"为什么这么写"时的那句"因为好玩"。
