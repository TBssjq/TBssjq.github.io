指针

9月18日

C/C++ 指针、数组、参数传递、引用、UB 与动态数组详细合集（NASM 汇编完善版）

汇编约定：x86-64 System V ABI，NASM 语法（Intel 风格），GCC/Clang -O0 风格示意。汇编用于理解底层，不保证与实际编译结果逐字节相同。

1. 阅读约定与关键结论

1.1 汇编约定

  • 平台：x86-64 System V。
  • 语法：NASM，Intel 风格。
  • 参数寄存器：rdi, rsi, rdx, rcx, r8, r9。
  • 返回值：rax。
  • 栈帧：push rbp; mov rbp, rsp; ...; pop rbp; ret。
  • 全局变量访问常用 [rel 符号]。

1.2 关键结论

  • C 只有值传递；C++ 默认值传递，但支持引用传递。

  • int *p = 6;

    • C 中：除 0 外，整数转指针结果实现定义，编译器通常警告；解引用通常是 UB。
    • C++ 中：除 0 外不允许隐式整数转指针，直接编译错误。
  • C 标准不保证所有指针大小相同。常见平台上数据指针大小通常相同，但函数指针可能不同。
  • sizeof(arr) 在数组定义处得到整个数组大小；在函数参数中得到的是指针大小。

  • 指针加法不是普通整数加法：

    ptr + i 等价于 (char *)ptr + i * sizeof(*ptr)
  • 指针自增、自减按所指向类型大小缩放。
  • 修改字符串字面量：C 中 char *s = "hello"; s[0] = 'H'; 是 UB；C++11 起 char *s = "hello"; 本身已非法或弃用。

2. C/C++ 函数传参

2.1 核心规则

C 语言函数传参全部是值传递。调用函数时，实参的值会被拷贝给形参，形参只是函数内部的局部变量。所谓“传地址”“传指针”，本质上也是值传递，只不过拷贝的是地址值。

C++ 默认同样是值传递，但额外支持引用传递：void f(int& x)。语法上不写 *，但底层通常仍用地址实现。

2.2 C：值传递，改形参不影响实参

void f(int x) {
    x = 99;
}

int main() {
    int a = 1;
    f(a);
    printf("%d\n", a); // 输出 1
}

调用 f(a) 时，只是把 a 的值 1 拷贝给形参 x。
x 是函数内部的局部变量，改它不影响 a。

2.3 C：传指针，本质还是值传递

void set(int *p) {
    *p = 99;
}

void reset(int *p) {
    p = NULL;
}

int main() {
    int a = 1;
    int *q = &a;

    set(q);
    printf("%d\n", a); // 输出 99

    reset(q);
    printf("%p\n", (void*)q); // q 仍然指向 a，没有被改成 NULL
}

set(q) 时，q 的地址值被拷贝给 p。
所以 p 和 q 指向同一个 a，*p = 99 能改 a。

但 reset(q) 里改的是 p 这个副本，不影响外面的 q。
这说明：传指针也是值传递，只不过拷贝的是地址值。

如果想真正把 q 改成 NULL，应该怎么做？

需要传递“指针的指针”：

void reset(int **p) {
    *p = NULL;
}

int main() {
    int a = 1;
    int *q = &a;

    reset(&q);
    printf("%p\n", (void*)q); // 输出空指针，通常是 (nil) 或 0x0
}

因为这时：

p == &q
*p == q

所以：

*p = NULL;

等价于：

q = NULL;

2.4 C++：默认也是值传递

void f(int x) {
    x = 99;
}

int main() {
    int a = 1;
    f(a);
    // a 仍然是 1
}

对象也一样：

void g(std::string s) {
    s += "!";
}

std::string t = "hi";
g(t);
// t 仍然是 "hi"，因为 s 是 t 的拷贝

2.5 C++：引用传递，形参是实参的别名

void f(int& x) {
    x = 99;
}

int main() {
    int a = 1;
    f(a);
    // a 变成 99
}

调用时不用写 &a，函数定义里也不用写 *x：

void g(std::string& s) {
    s += "!";
}

std::string t = "hi";
g(t);
// t 变成 "hi!"

语法上 x、s 就像普通变量，但语义上它们是实参的别名。
底层通常还是通过地址实现，但这是编译器实现细节。

2.6 C++：const 引用，避免拷贝又能只读

void print(const std::string& s) {
    std::cout << s << std::endl;
    // s += "!"; // 不行，const 不能改
}

std::string t = "hello";
print(t);

const std::string& 常用于大对象传参：
不拷贝对象，同时保证函数内部不能修改它。

2.7 swap 函数：int t 能否换成 int *t

原始代码：

void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

问题：中间的 int t 可不可以换成 int *t？

答案：不能直接换。

原因：

  • *a 是 int 类型的值。
  • int *t 是“指向 int 的指针”类型。
  • 类型不匹配。

错误写法：

int *t = *a;     // 左边指针，右边 int，类型不匹配
int *t; *t = *a; // t 未初始化，野指针，UB
int *t = a;      // 类型匹配，但 t 保存地址，不是旧值

如果写成 int *t = a;，那么 t 和 a 指向同一块内存。后面执行 *a = *b; 时，*t 也会跟着变，无法保存原来的值。

正确写法仍然是：

void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

这里的 t 保存的是“值”，所以必须是 int，不是 int *。

2.8 不同场景

  • 基本类型：void f(int x)，修改 x 不影响外部实参。

  • 指针传参：想修改外部变量，必须传地址。

    void swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }
  • 数组传参：数组名退化为指向首元素的指针，int arr[] 等价于 int *arr。sizeof(arr) 得到的是指针大小，不是数组总大小，因此必须额外传长度。
  • 结构体/大对象：按值传递会拷贝整个对象，开销大，通常传指针。只读时加 const。

  • 修改指针本身：C 中必须传二级指针。

    void alloc(int **p) { *p = malloc(sizeof(int)); }

    C++ 中也可以用指针的引用：

    void alloc(int *&p) { p = new int; }

一句话：C 只有值传递。想改外面的值，传地址；想改外面的指针，传二级指针或指针引用。

2.9 swap 函数怎么使用

#include <stdio.h>

void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

int main() {
    int x = 3, y = 5;
    swap(&x, &y);   // 传地址
    printf("x=%d, y=%d\n", x, y); // x=5, y=3
    return 0;
}

关键点：

  • swap(&x, &y); 中的 &x 是取 x 的地址，类型是 int *。
  • 函数里的 a 接收到 &x，所以 *a 就是 x。
  • 函数里的 b 接收到 &y，所以 *b 就是 y。
  • 如果已经是指针变量：int *p = &x; int *q = &y; swap(p, q);
  • 如果是数组元素：swap(&arr[0], &arr[1]);

不能写 swap(x, y);，因为类型不匹配。

2.10 汇编视角：值传递、指针传递、swap（NASM）

; int f(int x) { return x + 1; }
f:
    push rbp
    mov rbp, rsp
    mov dword [rbp-4], edi      ; 形参 x 是实参的拷贝
    mov eax, dword [rbp-4]
    add eax, 1
    pop rbp
    ret

; void swap(int *a, int *b)
swap:
    push rbp
    mov rbp, rsp
    mov qword [rbp-8], rdi      ; a
    mov qword [rbp-16], rsi     ; b
    mov rax, qword [rbp-8]
    mov eax, dword [rax]        ; *a
    mov dword [rbp-20], eax     ; t = *a
    mov rax, qword [rbp-16]
    mov eax, dword [rax]        ; *b
    mov rdx, qword [rbp-8]
    mov dword [rdx], eax        ; *a = *b
    mov rax, qword [rbp-16]
    mov edx, dword [rbp-20]
    mov dword [rax], edx        ; *b = t
    pop rbp
    ret

; 调用 swap(&x, &y)
    lea rdi, [rel x]
    lea rsi, [rel y]
    call swap

2.11 交换两个 int 变量的地址（交换指针）

在 C++ 中，变量本身的地址是固定的，无法交换两个 int 变量在内存中的位置。通常所说的“交换地址”是指交换指向这些变量的指针，让两个指针互相指向对方原来指向的地址。

方法一：使用指针的引用
#include <iostream>

// 交换两个 int* 指针，即交换它们所保存的地址
void swapAddress(int*& a, int*& b) {
    int* temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 10, y = 20;
    int* p1 = &x;
    int* p2 = &y;

    std::cout << "交换前：\n";
    std::cout << "p1 指向 " << *p1 << "，地址 " << p1 << "\n";
    std::cout << "p2 指向 " << *p2 << "，地址 " << p2 << "\n";

    swapAddress(p1, p2);   // 交换指针，而不是交换 x 和 y 的值

    std::cout << "\n交换后：\n";
    std::cout << "p1 指向 " << *p1 << "，地址 " << p1 << "\n";
    std::cout << "p2 指向 " << *p2 << "，地址 " << p2 << "\n";

    return 0;
}

输出示例：

交换前：
p1 指向 10，地址 0x7ffd...
p2 指向 20，地址 0x7ffd...
交换后：
p1 指向 20，地址 0x7ffd...  // 原来 p2 的地址
p2 指向 10，地址 0x7ffd...  // 原来 p1 的地址

注意：x 和 y 的值并没有改变，只是 p1 和 p2 指向的目标互换了。

方法二：使用标准库 std::swap

如果只是交换两个指针，直接使用 std::swap 即可：

#include <utility>  // 或 <algorithm>

std::swap(p1, p2);
方法三：使用二级指针（C 风格）
void swapAddress(int** a, int** b) {
    int* temp = *a;
    *a = *b;
    *b = temp;
}
// 调用：swapAddress(&p1, &p2);
关键点
  • 不能交换 int 变量本身的地址：变量地址由编译器分配，在作用域内固定不变。
  • 只能交换指向 int 的指针：通过交换指针的值，间接实现“交换地址”的效果。
  • 如果希望函数内部修改指针本身，必须传递指针的引用（int*&）或指针的指针（int**）。

2.12 *& 和 ** 有什么区别

在 C++ 中，*& 和 ** 出现在类型声明里时，含义完全不同。int*& 和 int** 就是典型对比。

本质区别
  • int*&：这是一个引用，引用的是一个 int* 类型的指针变量。
    读作：“指向 int 的指针的引用”。
    它相当于给一个指针变量起了个别名，操作它就是在操作原指针。
  • int**：这是一个二级指针，它本身是一个指针，指向另一个 int* 类型的指针变量。
    读作：“指向（指向 int 的指针）的指针”。
    它保存的是“指针变量的地址”。
代码对比
int x = 10;
int* p = &x;      // p 是指向 int 的指针

int*& ref = p;    // ref 是 p 的引用，ref 就是 p
int** pp = &p;    // pp 是二级指针，指向 p
访问方式
操作 int*& ref int** pp
访问 x 的值 *ref **pp
修改 p 的指向 ref = nullptr; *pp = nullptr;
修改 x 的值 *ref = 20; **pp = 20;
作为函数参数的区别
使用 int*&（C++ 推荐）
void swapPtr(int*& a, int*& b) {
    int* temp = a;
    a = b;
    b = temp;
}

int main() {
    int x = 1, y = 2;
    int* p1 = &x;
    int* p2 = &y;
    swapPtr(p1, p2);   // 直接传指针变量
}
  • 引用必须绑定到一个已存在的指针变量。
  • 函数内部对 a、b 的修改会直接改变 p1、p2。
  • 引用不能为空，也不能重新绑定到别的变量。
使用 int**（C 风格）
void swapPtr(int** a, int** b) {
    int* temp = *a;
    *a = *b;
    *b = temp;
}

int main() {
    int x = 1, y = 2;
    int* p1 = &x;
    int* p2 = &y;
    swapPtr(&p1, &p2); // 必须传指针的地址
}
  • 二级指针可以为空，也可以重新指向别的指针变量。
  • 函数内部需要多一次解引用 *a 才能操作原来的指针。
核心差异总结
特性 int*&（指针的引用） int**（二级指针）
本质 引用（别名） 指针（保存地址）
能否为空 否 是
能否重新绑定/指向 否（引用一旦绑定不可变） 是
修改原指针 a = ... *a = ...
访问最终 int *a **a
函数调用 func(p) func(&p)
风格 C++ 惯用，更安全直观 C 风格，更底层
注意
  • *& 不是一个独立的运算符，而是类型声明中的符号组合。
    在表达式中，*&p 等价于 p（先取地址再解引用），但这和类型声明 int*& 是两回事。
  • int&* 是非法的：不能定义“指向引用的指针”。
  • 如果只是想在函数里修改指针本身，优先用 int*&；只有在需要兼容 C 或处理更复杂的多级间接时，才用 int**。

简单记：
int*& 是指针的别名，int** 是指针的地址。

3. * 的含义与指针类型

3.1 * 的三种用法

场景 例子 含义
声明指针 int *p; p 是 int * 类型
解引用 *p 取 p 指向的值，类型是 int
乘法 a * b 普通乘法

在声明里，* 不是解引用，而是指针声明符的一部分。
在表达式里，*p 是一元运算符，叫“解引用”或“间接访问”。

例子：

int x = 10;
int *p = &x;      // p 存的是 x 的地址
printf("%d", *p); // *p 就是 x，输出 10
*p = 20;          // 通过 p 修改 x

* 和 & 有点像反操作：

  • &x：取 x 的地址
  • *p：根据地址找值

3.2 int *a 为什么不是 int 类型，而是 int * 类型

int x = 10;
int *a = &x;
写法 含义 类型
a 指针变量，存的是 x 的地址 int *
*a 解引用，得到 x 的值 int
&x 取 x 的地址 int *

所以：

  • a 是 int * 类型。
  • *a 是 int 类型。

回到 swap：

void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}
  • 参数 int *a 表示 a 是 int * 类型。
  • 函数体里的 *a 表示 a 指向的那个 int 值，类型是 int。
  • 所以 int t = *a; 中 t 必须是 int，不能是 int *。

3.3 指针声明中的括号问题

定义：

int arr[6]{0, 1, 2, 3, 4, 5};
  • int *p{arr};：声明 int* p，用 arr 初始化，p 指向 arr[0]。
  • int (*p){arr};：在 C++ 中与上面等价，括号只是把 *p 括起来，没有跟数组维度或函数参数，因此不改变含义。不推荐这样写。
  • int *p{&arr};：错误。p 是 int*，&arr 是 int(*)[6]，类型不匹配。

正确写法：

int *p{arr};          // 指向首元素
int *p{&arr[0]};      // 指向首元素
int (*p)[6]{&arr};    // 指向整个数组

3.4 所有指针的大小都一样吗

不绝对。

  • 32 位系统上，int *、char *、double *、struct *、void * 通常都是 4 字节。
  • 64 位系统上，通常都是 8 字节。

在普通 PC、服务器、手机这些平台上：

sizeof(int *) == sizeof(char *) == sizeof(void *)

一般成立。

但 C 标准不保证所有指针大小相同：

  • 函数指针和对象指针可能不一样大。
  • 某些嵌入式平台、老式架构里，int * 和 char * 可能不一样大。
  • 哈佛架构中，代码空间和数据空间地址宽度不同。
  • 早期 x86 有 near/far 指针，大小也不同。

void * 比较特殊：任何对象指针都可以转换成 void *，再转回来，值不变。但这不意味着所有对象指针一定大小相同，只是实际平台上通常相同。

函数指针和对象指针在 C 标准里不能随便互相转换。在某些平台上，函数指针可能和 void * 大小不同。

最安全的是用 sizeof(指针类型)，不要硬编码假设。

3.5 汇编视角：解引用（NASM）

; int x = 10; int *p = &x; int y = *p; *p = 20;
    mov dword [rel x], 10
    lea rax, [rel x]
    mov qword [rel p], rax

    mov rax, qword [rel p]
    mov eax, dword [rax]        ; y = *p
    mov dword [rel y], eax

    mov rax, qword [rel p]
    mov dword [rax], 20         ; *p = 20

4. 指针自增与自减

4.1 基本规则

指针自增、自减不是简单地址加 1，而是按所指向类型的大小缩放：

p + 1 等价于 (char *)p + sizeof(*p)
p++   使 p 指向下一个元素
p--   使 p 指向上一个元素

例如：

  • int *p; p++; 地址增加 sizeof(int)，常见为 4。
  • char *p; p++; 地址增加 1。
  • double *p; p++; 地址增加 sizeof(double)，常见为 8。
  • int **p; p++; 地址增加 sizeof(int *)，64 位常见为 8。

4.2 常见表达式区别

设：

int arr[3] = {10, 20, 30};
int *p = arr;
表达式 含义 指针是否移动 值变化 表达式结果
p++ 后缀自增 是，指向下一个 不改值 旧指针
++p 前缀自增 是，指向下一个 不改值 新指针
p-- 后缀自减 是，指向上一个 不改值 旧指针
--p 前缀自减 是，指向上一个 不改值 新指针
*p++ 等价 *(p++) 是 取旧位置值 旧位置的值
*++p 等价 *(++p) 是 取新位置值 新位置的值
(*p)++ 对 *p 做后缀加 否 值加 1 旧值
++*p 等价 ++(*p) 否 值加 1 新值

重点：

  • *p++ 和 (*p)++ 完全不同。
  • *p++ 先取当前 p 指向的值，然后 p 自增。
  • (*p)++ 不移动 p，只把 p 指向的值加 1。
  • *++p 先移动 p，再取新位置的值。
  • ++*p 不移动 p，只把 p 指向的值加 1。

4.3 示例

int arr[3] = {10, 20, 30};
int *p = arr;

int a = *p++;   // a = 10，p 指向 arr[1]
int b = *p;     // b = 20

p = arr;
int c = (*p)++; // c = 10，arr[0] 变成 11，p 仍指向 arr[0]
int d = *p;     // d = 11

p = arr;
int e = *++p;   // p 指向 arr[1]，e = 20

p = arr;
int f = ++*p;   // arr[0] 变成 11，f = 11，p 不变

4.4 常见陷阱

  • *p++ 不是 (*p)++。
  • p++ 作为表达式返回旧指针，++p 返回新指针。

  • 函数内部对指针形参自增，只改变局部副本，不影响调用者。

    void f(int *p) {
    p++;      // 只改局部 p
    *p = 99;  // 可能写到原 p 的下一个位置
}
  • 空指针、悬空指针、越界指针做自增或解引用通常是 UB。
  • 指针可以指向数组末尾后一个位置，但不能解引用该位置。
  • p + i 不修改 p；p += i 和 p++ 会修改 p。

4.5 汇编视角：指针自增（NASM）

; int *p; p++;
    mov rax, qword [rel p]
    add rax, 4                  ; sizeof(int)
    mov qword [rel p], rax

; ++p;
    mov rax, qword [rel p]
    add rax, 4
    mov qword [rel p], rax

; (*p)++;
    mov rax, qword [rel p]
    mov ecx, dword [rax]
    add ecx, 1
    mov dword [rax], ecx        ; p 不变，值加 1

; *p++;
    mov rax, qword [rel p]      ; 旧 p
    mov ecx, dword [rax]        ; 取旧位置的值
    add rax, 4
    mov qword [rel p], rax      ; p 自增
    ; ecx 保存取出的旧值

; *++p;
    mov rax, qword [rel p]
    add rax, 4
    mov qword [rel p], rax      ; 先自增
    mov ecx, dword [rax]        ; 再取新位置的值

; ++*p;
    mov rax, qword [rel p]
    mov ecx, dword [rax]
    add ecx, 1
    mov dword [rax], ecx        ; p 不变，值加 1

5. 数组与指针

5.1 数组名 arr 与 &arr 的区别

定义：

int arr[6]{0, 1, 2, 3, 4, 5};
表达式 类型 含义
arr int[6]，大多数表达式中退化为 int* 指向首元素 arr[0]
&arr[0] int* 指向首元素 arr[0]
&arr int(*)[6] 指向整个数组 arr

三者地址值通常相同，但类型完全不同，能做的事情也不同。

5.2 arr[0] 和 *arr 为什么一样

C 语言规定：

arr[i]  等价于  *(arr + i)

所以当 i = 0 时：

arr[0]  等价于  *(arr + 0)  等价于  *arr

即：

arr[0]  ==  *arr

这里 arr 在表达式中会变成“指向首元素的指针”，也就是 int *，指向 arr[0]。

5.3 函数参数 int arr[] 和 int *arr 为什么一样

当你写：

void func(int arr[]);

编译器实际上会把它调整成：

void func(int *arr);

因为数组作为函数参数时，不会把整个数组复制进去，而是传首元素的地址。所以下面完全等价：

void func(int arr[]);
void func(int *arr);
void func(int arr[10]); // 10 会被忽略

5.4 但数组不是指针

虽然数组名在很多表达式中会变成指针，但数组本身和指针是不同类型。

int arr[5];
int *p = arr;   // arr 退化成 int *

但是：

sizeof(arr)   // 整个数组大小，比如 5 * sizeof(int)
sizeof(p)     // 指针大小，比如 8 字节

&arr 的类型是 int (*)[5]，指向整个数组；
&p 的类型是 int **，指向指针变量。

数组名在表达式中会退化成指向首元素的指针，但数组本身不是指针。

5.5 指针数组 vs 数组指针

int m[2][3] = { {1,2,3}, {4,5,6} };
int *q[2] = { m[0], m[1] };
  • q 是指针数组，两个元素都是 int*。
  • q[0] 是 m[0]，类型 int*，指向 1。
  • q[1] 是 m[1]，类型 int*，指向 4。
  • q[1][2] 等价于 *(q[1] + 2)，也等价于 *(*(q + 1) + 2)，取到 6。
  • q[1] 已经是指针，后面的 [2] 已经包含“偏移 + 解引用”，所以不需要在 q 前面再加 *。
  • *q[1] 等价于 q[1][0]，得到 4。
  • *q[1][2] 错误，因为 q[1][2] 已经是 int，不能再解引用。

对比数组指针：

int (*p)[3] = m;
p[1][2]; // 输出 6
  • p 是数组指针，p[1] 得到 m[1] 这个数组，再 [2] 取到 6。
  • q 是指针数组，q[1] 直接得到 int*，再 [2] 也取到 6。

核心：q[1][2] 中的两个 [] 已经完成“先取指针，再解引用”的过程，所以 q 前不需要再加 *。

5.6 p[x]、*p[x]、(*p)[x]

  • p[x] 等价于 *(p + x)，只要指针有效且不越界就合法。
  • 注意 p[x] 是相对于当前 p 的位置。如果 ++p，p[0] 就变成原来的 arr[1]。

  • 运算符优先级：后缀 [] 高于一元 *。

    • *p[x] 等价于 *(p[x])，不是 (*p)[x]。
    • 当 p 是 int* 时，p[x] 是 int，再写 *p[x] 就是错误，因为不能对 int 解引用。
    • 当 p 是 int** 时，p[x] 是 int*，*p[x] 才合法。

  • (*p)[x]：先解引用 p，再对结果做下标。

    • 若 p 是 int*，*p 是 int，不能 [x]，错误。
    • 若 p 是 int(*)[N]，*p 是整个数组，(*p)[x] 合法，等价于 arr[x]。

5.7 指针加法：*(arr + i) 如何相加

关键点：

指针加法不是普通整数加法，它会按“所指向类型的大小”自动缩放。

如果 arr 是 int *，那么：

arr + i  →  (地址值) + i * sizeof(int)

假设 a[0] 的地址是 1000：

表达式 地址计算 结果地址 取出的值
arr 1000 1000 a[0] = 10
arr + 0 1000 + 0*4 1000 a[0] = 10
arr + 1 1000 + 1*4 1004 a[1] = 20
arr + 2 1000 + 2*4 1008 a[2] = 30

规则：

ptr + i  →  (char *)ptr + i * sizeof(*ptr)

所以：

  • int *arr，arr + i 实际加的是 i * 4。
  • char *arr，arr + i 实际加的是 i * 1。
  • double *arr，arr + i 实际加的是 i * 8。
  • int **arr，arr + i 实际加的是 i * 8（指针大小）。

5.8 指针和数组混合使用

数组和指针关系紧密，但要注意“退化”和“类型”。

1. 下标与指针等价
int arr[5] = {10, 20, 30, 40, 50};
int *p = arr;

arr[2] == *(arr + 2);
p[2]   == *(p + 2);
*(p + 2) == p[2];

当 p = arr 时：

arr[i] == *(arr + i) == *(p + i) == p[i]

甚至下面也合法，但不建议写：

i[arr] 等价于 *(i + arr)，也等价于 arr[i]
2. 用指针遍历数组
int arr[5] = {10, 20, 30, 40, 50};
int sum = 0;

for (int *p = arr; p != arr + 5; ++p) {
    sum += *p;
}

注意：

  • arr + 5 是数组末尾后一个位置，可以用于比较。
  • 不能解引用 arr + 5。
  • ++p 让指针按 sizeof(int) 移动。
3. 函数参数中的混合使用
void print(int *p, int n) {
    for (int i = 0; i < n; ++i) {
        printf("%d ", p[i]);
    }
}

int main() {
    int arr[3] = {1, 2, 3};
    print(arr, 3);  // arr 退化为 int*
}

下面几种函数参数写法等价：

void f(int arr[]);
void f(int arr[10]);
void f(int *arr);

但 sizeof(arr) 在函数内都是指针大小。

4. 二维数组与指针
int a[2][3] = { {1, 2, 3}, {4, 5, 6} };
  • a 的类型是 int[2][3]，表达式中退化为 int (*)[3]。
  • a + 1 跳过一整行，偏移 3 * sizeof(int)。
  • a[i] 是 int[3]，表达式中退化为 int*。
  • a[i][j] 等价于 *(*(a + i) + j)。

正确使用行指针：

int (*p)[3] = a;
p[1][2];   // 6

错误用法：

int **q = a;  // 类型不兼容

二维数组不是 int **。int ** 通常用于“指针数组”或动态分配的二级指针。

线性遍历二维数组：

int *p = &a[0][0];
for (int i = 0; i < 6; ++i) {
    printf("%d ", p[i]);
}
5. 字符串数组与 char **
char *argv[] = { "hello", "world", NULL };

作为函数参数时：

void f(char *argv[]);
void f(char **argv);  // 等价

argv[i] 是 char*，argv[i][j] 是 char。

5.9 汇编解释数组和指针（NASM）

C 代码：

int arr[3] = {10, 20, 30};
int *p = arr;

int a = arr[1];
int b = p[1];
int c = *arr;

数据段：

section .data
arr:
    dd 10          ; arr[0]
    dd 20          ; arr[1]
    dd 30          ; arr[2]
p:
    dq arr         ; p 是一个指针变量，里面存的是 arr 的地址

访问：

    mov eax, dword [rel arr+4]    ; a = arr[1]
    mov rax, qword [rel p]        ; 把 p 的值加载到 rax
    mov eax, dword [rax+4]        ; b = *(p + 1)
    mov eax, dword [rel arr]      ; c = *arr

关键区别：

  • 数组名 arr 直接就是地址，编译器知道它在哪。
  • 指针 p 是“存放地址的变量”，必须先读 p 才能得到地址。

函数参数中的数组：

void func(int arr[], int n) {
    arr[0] = 100;
}

int main() {
    int myarr[3] = {1, 2, 3};
    func(myarr, 3);
}

汇编：

    lea rdi, [rel myarr]    ; 把 myarr 的地址放入第一个参数寄存器
    mov esi, 3              ; 第二个参数 n = 3
    call func

func:
    push rbp
    mov rbp, rsp
    mov qword [rbp-8], rdi       ; arr 指针
    mov dword [rbp-12], esi      ; n
    mov rax, qword [rbp-8]
    mov dword [rax], 100         ; arr[0] = 100
    pop rbp
    ret

指针加法汇编：

; int *p 在 rax
    mov eax, dword [rax+4]      ; p[1]，偏移 4

; char *p 在 rax
    movzx eax, byte [rax+1]     ; p[1]，偏移 1

; double *p 在 rax
    movsd xmm0, qword [rax+8]   ; p[1]，偏移 8

6. C++ 初始化、窄化转换、空指针

6.1 列表初始化 {}

int a{5}; 是 C++11 及以后的列表初始化/统一初始化，C 和旧 C++ 不支持。
它等价于 int a = 5; 或 int a(5);，但优势是禁止窄化转换。

6.2 窄化转换

窄化转换：把值转换成范围更小或精度更低的类型，导致原值可能无法完整表示。

常见场景：

  • 整数变窄：int x = 300; char c = x; 可能截断。若目标是有符号类型且值超出范围，结果通常实现定义或截断，不一定是 UB；列表初始化会禁止。
  • 浮点转整数：double d = 3.9; int i = d; 小数向零截断；若整数部分超出目标整数范围，行为未定义。
  • 双精度转单精度：float f = 1.23456789; 精度丢失；若值超出目标范围，可能 UB。
  • 有符号转无符号：int a = -1; unsigned int b = a; 变成大正数，按模运算。

C 与 C++ 差异：

int x = 3.14; // C 中合法，通常警告，x = 3
int x{3.14};  // C++ 编译错误！列表初始化禁止窄化

因此 {} 被称为“最安全的初始化方式”。

6.3 指针初始化陷阱

  • int *p = 6;

    • C 中：整数可以转指针，除 0 外结果实现定义，编译器通常警告；若放行，p 指向地址 6，解引用通常段错误，属于 UB。
    • C++ 中：除 0 外，整数不能隐式转指针，直接编译错误。

  • 合法空指针：

    • C++11 前：int *p = 0;
    • C++11 起：int *p = nullptr;
    • C：int *p = NULL;

  • 若非要指向特定地址，必须显式转换：

    int *p = (int*)6;
int *p = reinterpret_cast<int*>(6);

    仍然极度危险。

6.4 int(*p) 和 int* p

在函数参数中，void print(int(*p)) 和 void print(int* p) 完全等价。
* 在语法上绑定变量 p，int *p 容易让人误以为 int* 是整体类型。
括号写法主要用于复杂声明，如数组指针 int (*p)[10];、函数指针 int (*p)(int);。统一加括号只是风格。

7. 引用与指针

int a{10};
int &b{a};
int *c{&a};
特性 int a 变量 int &b 引用 int *c 指针
本质 数据本身 数据的别名 存放地址的变量
独立内存 有 无，与 a 共享 有，独立存放地址
修改值 a = 5; b = 5; 改的是 a *c = 5; 改的是 a
访问地址 &a &b 等于 &a c
能否为空 否 否 是，nullptr
能否改绑 — 否，终身绑定 是，可指向其他变量

形象理解：

  • 变量 a：房子本身。
  • 引用 b：给房子挂的门牌号，从 b 进去就是 a，必须初始化且不能改绑。
  • 指针 c：写着房子地址的纸条，可以改地址，也可以为空。

汇编视角：引用通常按指针实现（NASM）

8. 未定义行为 UB 与悬空指针

8.1 什么是 UB

UB = Undefined Behavior，未定义行为。C++ 标准不规定其行为，编译器可任意处理。程序一旦执行到 UB，整体行为不再有任何保证：可能正常、崩溃、错误结果，甚至被优化成无法理解的代码。

8.2 常见 UB

  • 数组越界：a[3] = 0;
  • 有符号整数溢出：int x = INT_MAX; x++;
  • 空指针解引用：int *p = nullptr; *p = 1;
  • 读取未初始化变量
  • 除零
  • 释放后使用：delete q; *q = 2;
  • 返回局部变量的引用或指针
  • 修改字符串字面量：C 中 char *s = "hello"; s[0] = 'H'; 是 UB；C++11 起 char *s = "hello"; 本身已非法或弃用。
  • 对空指针、悬空指针、越界指针做自增或解引用。

8.3 悬空指针案例

int main() {
    int *p{nullptr};
    {
        int a = 5;
        p = &a;
    } // a 生命周期结束，内存被回收
    print(p); // p 成为悬空指针
}

花括号创建局部作用域。执行到 } 时 a 被销毁，但 p 仍保存旧地址。此时 p 是悬空指针，不等于 nullptr。

void print(int(*p)) {
    if (p == nullptr) { /* ... */ return; } // 无法拦截悬空指针
    std::cout << (*p) << std::endl;          // 访问已销毁内存，UB
}

因此，p == nullptr 只能判断空指针，不能判断悬空指针。

8.4 UB 为什么危险

编译器可以假设程序永远不会执行 UB，并据此优化。

  • 编译通过 ≠ 没有 UB
  • 程序能跑 ≠ 没有 UB
  • 今天能跑 ≠ 换编译器还能跑

8.5 如何避免 UB

  • 打开编译警告：-Wall -Wextra -Wpedantic -Wconversion
  • 使用 Sanitizer：-fsanitize=address,undefined
  • 静态分析：clang-tidy、cppcheck
  • 多用现代 C++：std::vector、std::array、std::string、智能指针、std::optional、std::variant、std::span
  • 避免裸指针和手动 new/delete

8.6 汇编视角：返回局部变量地址（NASM）

; int* dangle() { int a = 5; return &a; }
dangle:
    push rbp
    mov rbp, rsp
    sub rsp, 16
    mov dword [rbp-4], 5
    lea rax, [rbp-4]      ; 返回局部变量地址
    leave
    ret                   ; 返回后该栈帧失效，rax 成悬空地址

9. 手写 C++ 动态数组

9.1 要解决的问题

原始写法：

int n;
std::cin >> n;
int* array = new int[n];
// 输入、逆序输出
delete[] array;

问题是数组大小固定，无法自动扩容，且必须手动释放内存。

9.2 核心设计

三个成员变量：

  • int* data：指向堆区真实存储数据的内存。
  • size_t size：当前元素个数。
  • size_t capacity：当前最多能容纳的元素个数。

扩容魔法：当 size == capacity 时，申请更大内存（通常两倍），搬旧数据，释放旧内存。

9.3 关键实现思想

void reserve(size_t new_capacity) {
    if (new_capacity <= capacity) return;
    int* new_data = new int[new_capacity];
    std::copy(data, data + size, new_data);
    delete[] data;
    data = new_data;
    capacity = new_capacity;
}
  • push_back：如果 size == capacity，则 reserve(capacity == 0 ? 4 : capacity * 2)，然后写入 data[size]，size++。
  • 析构函数：~DynamicArray() { delete[] data; }，对象离开作用域自动释放，告别手动 delete[]。
  • 运算符重载：int& operator[](size_t index) 返回引用，可读可写；再加 const 版本。
  • getSize()、getCapacity() 获取状态。

9.4 使用示例

DynamicArray array;
for (int i = 0; i < n; ++i) {
    int val;
    std::cin >> val;
    array.push_back(val);
}
for (int i = array.getSize() - 1; i >= 0; --i) {
    std::cout << array[i] << ' ';
}

不需要手动 delete[]，析构函数自动释放。

9.5 进阶方向

  • 模板化：支持 double、std::string 等。
  • 迭代器：实现 begin()、end()，支持范围 for。
  • 三大法则：补拷贝构造、拷贝赋值，避免浅拷贝导致 double free。
  • 移动语义：移动构造、移动赋值，减少深拷贝。

9.6 汇编视角：扩容关键动作（NASM）

; reserve 扩容关键动作示意
    mov rdi, qword [rel new_capacity]
    shl rdi, 2                  ; new_capacity * sizeof(int)
    call _Znam                  ; operator new[](unsigned long)
    mov qword [rel new_data], rax

    ; std::copy(data, data + size, new_data)
    ; ... 逐元素拷贝循环 ...

    mov rdi, qword [rel data]
    call _ZdaPv                 ; operator delete[](void*)

    mov rax, qword [rel new_data]
    mov qword [rel data], rax
    mov rax, qword [rel new_capacity]
    mov qword [rel capacity], rax

交换指针（地址） 交换的是指针变量的值，不是变量的地址；用 int*& 或 int**

int *a a 的类型是 int *；*a 的类型是 int

指针加法 ptr + i 实际加 i * sizeof(*ptr)；arr[i] 等价于 *(arr + i)
指针加法示例 int * 加 1 地址加 4；char * 加 1 地址加 1；double * 加 1 地址加 8
指针和数组混合 arr[i] == *(arr+i) == p[i]；二维数组 a[i][j] == *(*(a+i)+j)；int ** 不是二维数组
C++ 列表初始化 {} 禁止窄化转换，更安全
窄化转换 浮点转整数超出范围是 UB；整数变窄通常截断或实现定义
引用与指针 引用是别名，不能为空、不能改绑；指针可空、可改绑
UB 与悬空指针 悬空指针不等于 nullptr，解引用是 UB
动态数组 关键：data/size/capacity，满时两倍扩容，析构自动 delete[]

11. 常见错误速查

错误写法 问题
int *t = *a; 左边指针，右边 int，类型不匹配
int *t; *t = *a; t 未初始化，野指针，UB
swap(x, y); 参数应为 int *，应写 swap(&x, &y);
int *p = 6; C 中实现定义，C++ 中错误
函数内 sizeof(arr) 得到的是指针大小，不是数组总大小
*arr[i] 优先级问题，等价于 *(arr[i])，不是 (*arr)[i]
arr = p; 数组名不是可修改左值，不能赋值
&arr 与 arr 混用 类型不同：&arr 是 int (*)[N]，arr 退化后是 int *
int x{3.14}; C++ 列表初始化禁止窄化，编译错误
p == nullptr 判断悬空指针 只能判断空指针，不能判断悬空指针
*p++ 当成 (*p)++ *p++ 会移动指针，(*p)++ 不会
int **q = a; 二维数组 a 不是 int **，类型不兼容
试图交换 int 变量本身的地址 变量地址固定，不能交换；只能交换指向它们的指针
用 int** 时忘记解引用 int** 修改原指针需要 *a = ...；int*& 直接 a = ...

12. 记忆口诀

数组名，多退化，首元素地址就是它。
&数组，类型变，指向整个数组的指针。
声明看括号，(*p)[N] 才指数组。
下标 p[x] 就是 *(p+x)。
优先级 [] 高于 *，*p[x] 是 *(p[x])。
C 只有值传递，改外面传地址。
C++ 用 {} 防窄化，能用引用就别用指针，能用智能指针就别用裸指针，远离 UB。
swap 临时变量存值，int t 不能换 int *t。
交换地址换指针，int*& 或 int**，变量地址永不变。
int*& 是别名，不能为空不能改绑；int** 是地址，可空可改指向。
指针加法按类型缩放：int * 加 4，char * 加 1，double * 加 8。
数组不是指针，指针不是数组；数组名会退化，但 sizeof 不退化。
p++ 移指针，(*p)++ 改值，*p++ 先取值再移指针。
