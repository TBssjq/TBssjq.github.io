一、C/C++ 函数传参：只有“值传递”

1. 核心规则

C 语言函数传参全部是值传递。调用函数时，实参的值会被拷贝给形参，形参只是函数内部的局部变量。所谓“传地址”“传指针”，本质上也是值传递，只不过拷贝的是地址值。

2. 不同场景

  • 基本类型：void f(int x)，修改 x 不影响外部实参。
  • 指针传参：想修改外部变量，必须传地址。

```c
void swap(int a, int b) { int t = a; a = b; b = t; }
```
拷贝的是地址值，但通过解引用可以修改原内存。

  • 数组传参：数组名退化为指向首元素的指针，int arr[] 等价于 int *arr。sizeof(arr) 得到的是指针大小，不是数组总大小，因此必须额外传长度。
  • 结构体/大对象：按值传递会拷贝整个对象，开销大，通常传指针。只读时加 const。
  • 修改指针本身：必须传二级指针。

```c
void alloc(int *p) { p = malloc(sizeof(int)); }
```

一句话：C 只有值传递。想改外面的值，传地址；想改外面的指针，传二级指针。

二、指针与数组：类型、退化、声明、下标

1. 数组名 arr 与 &arr 的区别

定义：

int arr[6]{0, 1, 2, 3, 4, 5};

| 表达式 | 类型 | 含义 |
|---|---|---|
| arr | int*（大多数表达式中退化） | 指向首元素 arr[0] |
| &arr[0] | int* | 指向首元素 arr[0] |
| &arr | int(*)[6] | 指向整个数组 arr |

三者地址值通常相同，但类型完全不同，能做的事情也不同。

2. 指针声明中的括号问题

  • int *p{arr};：声明 int* p，用 arr 初始化，p 指向 arr[0]。
  • int (*p){arr};：和上面完全等价，括号只是把 *p 括起来，没有跟数组维度或函数参数，因此不改变含义。不推荐这样写。
  • int *p{&arr};：错误。p 是 int*，&arr 是 int(*)[6]，类型不匹配。
  • 正确写法：

```cpp
int *p{arr}; // 指向首元素
int *p{&arr[0]}; // 指向首元素
int (*p)[6]{&arr}; // 指向整个数组
```

3. p[x]、*p[x]、(*p)[x]

  • p[x] 等价于 *(p + x)，只要指针有效且不越界就合法。
  • 注意 p[x] 是相对于 当前 p 的位置。如果 ++p，p[0] 就变成原来的 arr[1]。
  • 运算符优先级：后缀 [] 高于一元 *。
  • *p[x] 等价于 *(p[x])，不是 (*p)[x]。
  • 当 p 是 int* 时，p[x] 是 int，再写 *p[x] 就是错误，因为不能对 int 解引用。
  • 当 p 是 int** 时，p[x] 是 int*，*p[x] 才合法。
  • (*p)[x]：先解引用 p，再对结果做下标。
  • 若 p 是 int*，*p 是 int，不能 [x]，错误。
  • 若 p 是 int(*)[N]，*p 是整个数组，(*p)[x] 合法，等价于 arr[x]。

4. 指针数组 vs 数组指针

原文开头重点例子：

int m[2][3] = { {1,2,3}, {4,5,6} };
int *q[2] = { m[0], m[1] };
  • q 是指针数组，两个元素都是 int*。
  • q[0] 是 m[0]，类型 int*，指向 1。
  • q[1] 是 m[1]，类型 int*，指向 4。
  • q[1][2] 等价于 *(q[1] + 2)，也等价于 *(*(q + 1) + 2)，取到 6。
  • q[1] 已经是指针，后面的 [2] 已经包含“偏移 + 解引用”，所以不需要在 q 前面再加 *。
  • *q[1] 等价于 q[1][0]，得到 4。
  • *q[1][2] 错误，因为 q[1][2] 已经是 int，不能再解引用。

对比数组指针：

int (*p)[3] = m;
p[1][2]; // 输出 6
  • p 是数组指针，p[1] 得到 m[1] 这个数组，再 [2] 取到 6。
  • q 是指针数组，q[1] 直接得到 int*，再 [2] 也取到 6。

核心：q[1][2] 中的两个 [] 已经完成“先取指针，再解引用”的过程，所以 q 前不需要再加 *。

三、C++ 初始化、窄化转换、空指针

1. 列表初始化 {}

int a{5}; 是 C++11 及以后 的列表初始化/统一初始化，C 和旧 C++ 不支持。
它等价于 int a = 5; 或 int a(5);，但优势是禁止窄化转换。

2. 窄化转换

窄化转换：把值转换成范围更小或精度更低的类型，导致原值可能无法完整表示。
核心：目标类型装不下源值，就可能截断、精度丢失，甚至未定义行为。

常见场景：

  • 整数变窄：int x = 300; char c = x; 可能截断。
  • 浮点转整数：double d = 3.9; int i = d; 小数向零截断；若整数部分超出目标整数范围，行为未定义。
  • 双精度转单精度：float f = 1.23456789; 精度丢失，超出范围可能 UB。
  • 有符号转无符号：int a = -1; unsigned int b = a; 变成大正数，按模运算。

C 与 C++ 差异：

int x = 3.14; // C 中合法，通常警告，x = 3
int x{3.14};  // C++ 编译错误！列表初始化禁止窄化

因此 {} 被称为“最安全的初始化方式”。

3. 指针初始化陷阱

  • int *p = 6;
  • C 中：非零整数不能隐式转指针，通常警告；若放行，p 指向地址 6，解引用通常段错误，属于 UB。
  • C++ 中：直接编译错误。
  • 合法空指针：
  • C++11 前：int *p = 0;
  • C++11 起：int *p = nullptr;
  • C：int *p = NULL;
  • 若非要指向特定地址，必须显式转换：

```cpp
int p = (int)6;
int p = reinterpret_cast<int>(6);
```
仍然极度危险。

4. int(*p) 和 int* p

在函数参数中，void print(int(*p)) 和 void print(int* p) 完全等价。
* 在语法上绑定变量 p，int *p 容易让人误以为 int* 是整体类型。
括号写法主要用于复杂声明，如数组指针 int (*p)[10];、函数指针 int (*p)(int);。统一加括号只是风格。

四、引用与指针

int a{10};
int &b{a};
int (*c){&a};

| 特性 | int a 变量 | int &b 引用 | int (*c) 指针 |
|---|---|---|---|
| 本质 | 数据本身 | 数据的别名 | 存放地址的变量 |
| 独立内存 | 有 | 无，与 a 共享 | 有，独立存放地址 |
| 修改值 | a = 5; | b = 5; 改的是 a | *c = 5; 改的是 a |
| 访问地址 | &a | &b 等于 &a | c |
| 能否为空 | 否 | 否 | 是，nullptr |
| 能否改绑 | — | 否，终身绑定 | 是，可指向其他变量 |

形象理解：

  • 变量 a：房子本身。
  • 引用 b：给房子挂的门牌号，从 b 进去就是 a，必须初始化且不能改绑。
  • 指针 c：写着房子地址的纸条，可以改地址，也可以为空。

五、未定义行为 UB 与悬空指针

1. 什么是 UB

UB = Undefined Behavior，未定义行为。C++ 标准不规定其行为，编译器可任意处理。程序一旦执行到 UB，整体行为不再有任何保证：可能正常、崩溃、错误结果，甚至被优化成无法理解的代码。

2. 常见 UB

  • 数组越界：a[3] = 0;
  • 有符号整数溢出：int x = INT_MAX; x++;
  • 空指针解引用：int *p = nullptr; *p = 1;
  • 读取未初始化变量
  • 除零
  • 释放后使用：delete q; *q = 2;
  • 返回局部变量的引用
  • 修改字符串字面量：char *s = "hello"; s[0] = 'H';

3. 悬空指针案例

int main() {
    int *p{nullptr};
    {
        int a = 5;
        p = &a;
    } // a 生命周期结束，内存被回收
    print(p); // p 成为悬空指针
}

花括号创建局部作用域。执行到 } 时 a 被销毁，但 p 仍保存旧地址。此时 p 是悬空指针，不等于 nullptr。
在 print 中：

void print(int(*p)) {
    if (p == nullptr) { ... return; } // 无法拦截悬空指针
    std::cout << (*p) << std::endl;   // 访问已销毁内存，UB
}

因此，p == nullptr 只能判断空指针，不能判断悬空指针。

4. UB 为什么危险

编译器可以假设程序永远不会执行 UB，并据此优化。

  • 编译通过 ≠ 没有 UB
  • 程序能跑 ≠ 没有 UB
  • 今天能跑 ≠ 换编译器还能跑

5. 如何避免 UB

  • 打开编译警告：-Wall -Wextra -Wpedantic -Wconversion
  • 使用 Sanitizer：-fsanitize=address,undefined
  • 静态分析：clang-tidy、cppcheck
  • 多用现代 C++：std::vector、std::array、std::string、智能指针、std::optional、std::variant、std::span
  • 避免裸指针和手动 new/delete

六、手写 C++ 动态数组

1. 要解决的问题

原始写法：

int n;
std::cin >> n;
int* array = new int[n];
// 输入、逆序输出
delete[] array;

问题是数组大小固定，无法自动扩容，且必须手动释放内存。

2. 核心设计

三个成员变量：

  • int* data：指向堆区真实存储数据的内存。
  • size_t size：当前元素个数。
  • size_t capacity：当前最多能容纳的元素个数。

扩容魔法：当 size == capacity 时，申请更大内存（通常两倍），搬旧数据，释放旧内存。

3. 关键实现思想

void reserve(size_t new_capacity) {
    if (new_capacity <= capacity) return;
    int* new_data = new int[new_capacity];
    std::copy(data, data + size, new_data);
    delete[] data;
    data = new_data;
    capacity = new_capacity;
}
  • push_back：如果 size == capacity，则 reserve(capacity == 0 ? 4 : capacity * 2)，然后写入 data[size]，size++。
  • 析构函数：~DynamicArray() { delete[] data; }，对象离开作用域自动释放，告别手动 delete[]。
  • 运算符重载：int& operator[](size_t index) 返回引用，可读可写；再加 const 版本。
  • getSize()、getCapacity() 获取状态。

4. 使用示例

用自己写的动态数组复刻“输入 n 个数，逆序输出”：

DynamicArray array;
for (int i = 0; i < n; ++i) {
    int val; std::cin >> val;
    array.push_back(val);
}
for (int i = array.getSize() - 1; i >= 0; --i) {
    std::cout << array[i] << ' ';
}

不需要手动 delete[]，析构函数自动释放。

5. 进阶方向

  • 模板化：支持 double、std::string 等。
  • 迭代器：实现 begin()、end()，支持范围 for。
  • 三大法则：补拷贝构造、拷贝赋值，避免浅拷贝导致 double free。
  • 移动语义：移动构造、移动赋值，减少深拷贝。

七、最终核心结论与口诀

核心结论

  1. C 语言只有值传递。想改外面的值，传地址；想改外面的指针，传二级指针。
  2. 数组名 arr 在大多数表达式中退化为 int*，指向首元素。
  3. &arr 类型是 int(*)[N]，指向整个数组，和 arr、&arr[0] 类型不同。
  4. int *p{arr}; 与 int (*p){arr}; 等价；int *p{&arr}; 错误。
  5. p[x] 等价于 *(p + x)，相对于当前指针位置。
  6. [] 优先级高于 *，所以 *p[x] 是 *(p[x])，不是 (*p)[x]。
  7. 指针数组 q[1] 已是 int*，q[1][2] 已包含解引用，不需要再加 *。
  8. C++ 列表初始化 {} 禁止窄化转换，更安全。
  9. 引用是别名，不能为空、不能改绑；指针可空、可改绑，但更危险。
  10. 悬空指针不等于 nullptr，解引用是 UB。
  11. 远离 UB：多用容器、智能指针、现代 C++，少用裸指针和手动内存管理。
  12. 手写动态数组的关键：data/size/capacity，满时两倍扩容，析构自动 delete[]。

记忆口诀

数组名，多退化，首元素地址就是它。

&数组，类型变，指向整个数组的指针。

声明看括号，(*p)[N] 才指数组。

下标 p[x] 就是 *(p+x)。

优先级 [] 高于 *，*p[x] 是 *(p[x])。

C 只有值传递，改外面传地址。

C++ 用 {} 防窄化，能用引用就别用指针，能用智能指针就别用裸指针，远离 UB。
